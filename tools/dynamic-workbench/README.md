# 动态整理与 Excel 合并

入口：`tools/dynamic-workbench/index.html`。直接在浏览器打开，或通过静态服务器访问。不改变仓库现有首页。

## 功能

- 可增加多条动态，每条对应一行；本地算法提取日期、标题、职位、领导级别。
- 标题综合议题、活动和机构；有明确会议名称时优先保留会议原名。
- 动态内容保留输入原文及换行、空格，不概括、不删减。
- 职位保留主要领导人名前的机构与职务；领导级别为“市级、区级、局级”等整理分类，不是法定行政级别。
- 预览可手动编辑，确认后导出 Excel。多份 Excel 可合并为单表头，按日期升序排列。
- 兼容旧版四列文件，新增的职位留空。新表头：日期、标题、动态内容、职位、领导级别。

## 隐私与限制

不调用 AI，无需 API 地址或密钥，不发送动态正文。猫咪图已内嵌页面。Excel 组件从 jsDelivr 加载，需要网络；组件加载后，本地分析、导出和合并无需服务端。

规则不能代替语义理解，复杂、多活动、多领导或陌生领域请人工核对；未识别信息标记待确认。页面不持久保存输入，刷新前请保存未导出的内容。

只需同时托管 `index.html` 与 `local-analyzer.js`，无需旧 AI 服务文件。没有附带真实密钥、配置或输入数据。
