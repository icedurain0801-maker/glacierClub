楼层抽奖管理 — 需求说明
v3.1.0 2026-05-18 最新 ▼
本次变更

楼层抽奖新增活动类型维度，拆分为「单次活动」与「周期活动」。单次活动逻辑沿用原版，仅多一个发奖方式字段（人工审核 / 自动发奖）；周期活动为本次新增形态，强制使用自动发奖（表单不展示发奖方式字段），支持活动时段、周期总数、活动说明三项基础配置，并在评论关键词「精准/模糊匹配」下新增「匹配类型」字段（统一 / 按周期配置），支持按周期下发不同关键词。

背景 & 目标

原楼层抽奖仅支持"一次性开奖"，无法承载连续 N 天打卡型运营玩法（如签到抽奖、每周话题抽奖）。本次扩展为"单次 + 周期"双形态，并通过周期级关键词配置，让运营可以按时间维度更换抽奖参与门槛。

运营配置时序流程
1
选择活动类型
默认「单次活动」。切换至「周期活动」后，截止时间字段隐藏，活动时段 / 周期徽标显示，开奖人数 label 变为「周期总数」。
2
填写时间字段
单次：填写截止日期与时间。
周期：填写活动时段（开始/结束日期），系统实时计算并显示 共 X 天 · X 个周期 徽标；每个周期的 24:00 自动发奖。
⚠ 新建时修改活动时段会触发周期重算，按周期配置的关键词将清空，前端二次确认；新建成功后活动时间不可修改。
3
配置开奖人数 / 周期总数
单次活动：直接输入开奖人数（≥ 1）。周期活动下默认不限，选「周期限制」时填入数字，作为每个周期获奖总人数上限。
4
选择发奖方式
仅单次活动需选择，默认「人工审核」。周期活动不展示该字段，系统固定为自动发奖，并显示 M<N 不补发 提示文案。
5
填写活动说明
可选，≤ 200 字。
6
配置参与条件 · 评论关键词
勾选「评论关键词」后选择匹配方式：
  • 不限：不需关键词，匹配类型与输入区整行隐藏
  • 精准 / 模糊 + 单次：直接 tag 输入
  • 精准 / 模糊 + 周期：出现「匹配类型」单选，默认统一（tag 输入）；切到按周期配置展开表格，按周期逐行录入 tag
7
校验保存
前端按异常场景规则校验全部字段，通过后落库。活动类型与发奖方式入库后受相应锁定规则约束。
周期活动 · 开奖触发时序
1
到达周期开奖时刻
调度任务按"周期日 + 24:00"触发自动发奖，逐周期独立计算，互不影响。
2
圈定本期达标用户
取本周期内满足参与条件的玩家（按周期配置时按该周期关键词匹配）。设达标人数 = M，开奖人数 = N。
3
系统自动发奖
周期活动固定走自动发奖：系统从达标玩家中随机抽取 min(N,M) 人，立即发奖，无需运营介入。
M = 0 → 本期流标，不消耗道具库存；M < N → 实发 M 人，剩余名额不补发。
4
结算本期 & 等待下一周期
写入开奖记录，标记本期状态。最后一个周期开奖完成后整个活动结束。

验收清单
  1. 新增页默认「单次活动 + 人工审核」，与历史交互一致
  2. 切到周期活动：截止时间隐藏、活动时段/周期徽标显示，开奖人数 label 联动「周期总数」，发奖方式字段整行隐藏
  3. 周期活动「周期总数」默认「不限」，选「周期限制」时出现人数输入框；提示文字：「周期内限制获奖的总人数」
  4. 周期活动：保存时发奖方式固定为 自动发奖；详情页和列表页该字段展示「自动发奖」
  5. 周期活动：显示 M<N 不补发 提示
  6. 评论关键词 + 周期 + 精准/模糊：显示「匹配类型」单选，默认「统一」
  7. 匹配类型切到「按周期配置」：自动按时段生成周期行，每行支持多 tag
  8. 匹配关键词切到「不限」：匹配类型 + 关键词输入整行隐藏
  9. 新建成功后编辑：活动类型、活动时间、周期总数、按周期配置评论关键词均不可修改
  10. 列表页活动类型 / 发奖方式列展示正确，老数据兼容
  11. 编辑已开奖活动：活动类型 / 发奖方式不可改
