## 重要设计决策

### 2026-04-07 — 徽章管理新增奖品选择字段
- **背景**：v3.0.9 需求，徽章可绑定道具/头像框奖励
- **决策**：奖品开关默认关闭，开启后显示奖品配置区；道具类型需填数量（最大 999999），头像框类型不需数量字段
- **上限**：游戏道具 + 头像框合计最多 5 个
- **展示**：已添加奖品以 pill 标签展示，右侧 × 可单独移除；"清空"按钮仅清空输入行

## 技术备注

- 当前所有页面均使用原生 HTML + CSS + JS，无框架依赖
- Mock 数据直接写在各页面的 `<script>` 标签内，无独立数据文件
- 需求说明浮窗（FAB）的需求内容由产品/运营在 `.help-panel-body` 内按版本维护
- 侧边栏导航数据在 `shared/sidebar-data.js` 中集中维护，新增页面后需同步更新该文件中的导航项
