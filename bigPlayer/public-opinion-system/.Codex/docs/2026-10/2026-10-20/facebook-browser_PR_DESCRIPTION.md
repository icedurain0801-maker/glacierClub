# Facebook 按社区独立账密采集配置

所有已启用境外社区都可在抓取账号管理新增 Facebook 网页采集来源，独立填写目标主页/群组及本社区账密。凭据加密保存，人工安全验证按账号隔离；修改目标或账密会停用来源并要求重新验证。旧 Graph 来源和历史数据保留，新来源默认停用。

API、前端、Worker、登录服务分别以其现役版本为基线合入本任务补丁，未发布整个工作区。没有数据库结构变更，没有补抓历史或发送钉钉。

验证：工作区 Facebook 回归 52/52；冻结候选后端核心回归 29/29；真实 Edge 隔离验证 12/12；管理员登录后的真实外网页面验证新增入口、社区切换、账密为空、关闭/Escape，以及概览/趋势/内容查询。未保存测试来源，未登录真实 Facebook。

登录服务当前测试集对冻结包为 35/36：唯一失败是独立 BigPlayer 选择器测试要求 `firstAvailable`，现役模块没有该方法，且候选模块与现役 SHA-256 一致。这项工作区测试与现役基线不匹配，不属于本次 Facebook 修改引入；未为通过测试混入其他开发变更。

真实 Facebook 帖子、评论、回复与安全验证兼容性仍须用一个社区的实际账号和页面完成验收，完成前不要启用新来源。
