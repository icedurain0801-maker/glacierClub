# 采集稳定性修复

## 问题

- Last Light 的海外语言配置接口一次瞬时失败会直接终止整批站点采集，记录为 `Q1_LANGUAGE_CONFIG_UNAVAILABLE`，发现和入库均为 0。
- 多站点父任务可能在最后一个站点提交前提前进入完成态，后续子任务虽然有新增，父任务统计仍保持 0。

## 修复

- `server/src/connectors/q1LanguageResolver.js`：配置读取增加有限重试；保存最近一次成功语言映射，在短时接口抖动期间使用短期缓存；无成功缓存时仍失败闭环，不使用默认语言伪造成功。
- `server/src/db/repository.js`：子任务终态落库时，父任务在已完成/部分完成状态也允许按全部终态子任务重新聚合。
- 运行包：API 继续使用 `api-release-20261014-baas-auth-recovery-r1`（已叠加聚合修复）；统一 Worker 切换到 `release-20261014-stability-worker-r2`（语言配置重试和父任务聚合）。旧包和 XML 备份保留。
- 已修复现有 X-Clash 父任务 `e79b6325-ddc4-427c-a55c-c20a17b36eb4`，当前展示：发现 3748、入库 2505、新增 105、变更 688、评论 1688。
