# 正面、中性情感百分比修复

Status: verified in live browser

## 规则与范围

- 正面、中性使用 TypeSafe `answers.sentiment.probabilities[当前情感]`；返回未提供概率分布且 choice 一致时，使用该情感问题的 confidence。
- 不使用风险等级 confidence，不使用 `1-negative_score`，不伪造缺失数值。
- 负面保持原来的 `negative_score` 显示值、计算及风险判级，不改变任何负面数据。
- 新结果将独立概率存入已有 `risk_context.rawAnalysis.sentimentScore`，查询接口输出 `sentiment_score`，不新增数据库列。
- 列表与详情采用同一百分比函数；缓存键增加情感字段版本，避免新内容命中没有情感概率的旧缓存。旧流程保持可用。

## 历史数据

近7天启用来源、未删除的正面/中性内容单独补算情感概率。只更新 JSON 中的情感概率字段并写审计；保留情感标签、负面分值、风险等级、分析时间、处理状态，不入队、不通知。使用原内容指纹、分析时间及原标签作并发保护，同文本复用响应，并发10。

2026-10-14：11124条候选，10599条更新，525条无可分析文字跳过，接口失败0，去重后调用7350次。无文字不制造百分比。7天之前历史数据不自动重判。
