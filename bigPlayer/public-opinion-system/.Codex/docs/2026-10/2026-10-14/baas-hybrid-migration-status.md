1. **后台服务身份**：公开接口只给员工 SSO 登录 token。未找到可由本机后台自行续期、限定本应用读写范围、可撤销的服务凭据。部署 Token 只可上传静态文件；不能充当数据库权限。当前浏览器 Cookie 或个人 token 不进入服务 env，也不能当作长期运行方案。

4. **前端上线**：待平台批准及 AI 检查完成，再验收真实托管页面。此时 API 数据仍来自本机 MySQL，必须如实说明阶段状态。

## 需要 BaaS 平台提供的具体能力

给本应用开通可供本机后台使用的服务身份，提供：

- 正式签发/续期接口或配置入口；令牌不依赖员工浏览器在线，不用个人 Cookie。
- 权限限定为本应用业务集合的读取、创建、更新；支持撤销及审计。
- token 获取、生命周期、过期/限流错误契约与安全配置方式。
- 若平台没有服务身份，可提供受保护的服务端写入代理及相同审计/权限保障；不要开放匿名读写。

服务身份到位后实施迁移适配器与断点工具，完整验证聚合结构、配额、历史/增量校验、导航与社区权限、网页处置回写和后台无人值守重启。确认数据权威切换成功后保留旧库作回退，不删除旧数据。
