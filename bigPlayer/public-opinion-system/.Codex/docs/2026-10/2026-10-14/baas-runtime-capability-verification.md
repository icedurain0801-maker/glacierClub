# BaaS 后台运行能力实测

时间：2026-10-14（北京时间）。范围：现有舆情应用控制台与实际应用任务接口；不修改现役业务。

## 已验证

- 控制台应用详情有定时任务、静态托管、集合 ACL、审批流程等栏目。
- 定时任务表单支持时间计划、集合/审批流查询、消息模板、AI 润色、钉钉推送；没有自定义代码、容器、浏览器或外部 HTTP 数据源配置。
- 当前线上控制台资源为 `BaaSConsole-Bmjttu1w.js`。检查其实际接口，存在 jobs、preview、run、runs 等接口，未发现代码运行/容器部署接口。此结论仅限当前控制台，不证明平台内部不存在此类能力。
- 使用现有授权凭证调用 `POST /baas/v1/app/jobs/preview`：集合计数返回 HTTP 200，`q1=6348`。
- 对同一预览接口传入 `source=http`：返回 HTTP 400，`查询块 q1: source 仅支持 collection/workflow`。现有任务查询源不接受外部采集请求。
- 设置 `ai.enabled=true` 后预览仍返回 HTTP 200，但模板输出没有变化，因此不能把该响应当作 AI 已实际执行的证据。
- `GET /baas/v1/app/jobs` 返回空列表。未保存任务、未调用 run、未发送消息、未写业务数据。

## 当前结论

已证明云端集合查询和任务预览可用。尚未证明可托管现有 Node.js API、采集/分析/翻译 Worker、Playwright 登录服务或自定义定时脚本。需要平台实际提供的后台运行入口或部署权限进一步验证，不能仅根据公开文档缺失断言平台不支持，也不能因任务接口存在就宣布整体迁移可行。

证据：`.tests/2026-10/2026-10-14/baas-runtime-capability-check.cjs` 与同名 JSON。凭证在进程内读取，报告不记录凭证或收件人标识。
