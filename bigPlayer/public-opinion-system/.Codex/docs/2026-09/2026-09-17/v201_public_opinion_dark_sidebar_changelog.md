# v201 舆情分析系统深色侧栏

## 修改

- 舆情六页启用独立侧栏数据源，保持六入口和单层结构，以“分析 / 采集”做纯视觉分组。
- 标题调整为“舆情分析系统”，副标题为“OPERATION CENTER”；移除搜索框、圆点占位和运营胶囊。
- 新增六枚无外部依赖的线性 SVG 图标。
- 专属侧栏宽度 232px，背景 `#182435`，选中背景 `#235077`，并补齐 hover 与键盘 focus 状态。
- 保留 `regionCode`、`communityId`、`platform` 作用域透传、active 判断和浏览器前进后退行为。
- PublicOpinion 路径作为唯一隔离门禁；非舆情后台继续使用原通用侧栏。
- 六页共享侧栏资源统一使用 `v=200` 版本参数，避免浏览器继续命中旧 CSS/JS 缓存。

## 可访问性

- 图标保持 `#7188a3`，非文本对比度满足 3:1。
- 键盘焦点使用 2px `#75c7ff` 轮廓。
