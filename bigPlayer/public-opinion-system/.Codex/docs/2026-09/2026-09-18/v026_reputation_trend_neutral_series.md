# 口碑趋势补充中性情感

## 一句话需求

口碑趋势不能只展示正面和负面，还要独立展示中性内容。

## 已确认现状

- `server/src/db/repository.js` 的趋势查询已经按日期返回 `positive`、`negative`、`neutral`、`unclassified` 和 `total`。
- `admin/PublicOpinion/assets/app.js` 的 `normalizeTrend()` 已保留 `neutral` 字段。
- 当前 `renderTrend()` 只渲染正面、负面两组柱状条，图例也只有正向和负面。
- 当前顶部摘要将正面和中性合并为“正向 / 中性内容”，无法单独查看中性占比。

## 需求口径

1. 口碑趋势图例增加“中性”，使用独立且不与正面/负面混淆的灰色系颜色。
2. 每个日期展示三组柱状条：正面、负面、中性；柱高按当日对应情感内容量，三类使用同一纵向比例尺。
3. 鼠标悬停/可访问文本必须同时展示该日期三类数量和总量。
4. 顶部摘要拆分为三项：正面率、负面率、中性率；不再显示“正向 / 中性内容”合并口径。
5. 无数据时沿用现有空状态；某一情感当日数量为 0 时不显示空柱，但不影响其他情感柱位置和日期对齐。
6. 数据仍使用当前右上角时间范围、地区-社区统一组件和平台筛选结果，不新增独立查询口径。
7. `unclassified` 不作为情感趋势主系列展示；如接口存在未分析数据，不得把它计入中性，应继续按现有未分析统计口径处理。

## 验收用例

- 同一日期存在正面、负面、中性三类内容时，图例、摘要和柱状图均显示三类。
- 只有中性内容时，正面率/负面率为 0，中性率为 100%，中性柱正常显示。
- 某日某类数量为 0 时不出现伪柱，另外两类仍按正确比例显示。
- 切换今天/昨天或自定义时间范围，三类数据同步变化。
- 切换地区-社区或平台后，三类趋势均只使用当前筛选范围数据。
- 接口返回 `unclassified` 时，页面不把未分析内容误标为中性。
- 桌面和 375px 浏览器下，三组柱状条、图例和三项摘要不重叠、不截断。

## 交接文件

- 前端：`admin/PublicOpinion/index.html`、`admin/PublicOpinion/assets/app.js`
- 数据接口核对：`server/src/db/repository.js`
- 回归范围：概览时间范围、统一地区-社区组件、平台筛选和移动端布局
