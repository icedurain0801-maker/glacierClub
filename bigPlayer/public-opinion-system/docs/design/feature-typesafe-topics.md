# TypeSafe 细分议题

Status: approved — 用户于 2026-10-14 确认“采用 TypeSafe 细分，并补判已有其他”。

## 范围与实现

新增内容在现有 System One 请求增加一个 `choice` 议题问题，返回一个主要语义议题。分类包含关卡副本、阵容搭配、角色养成、装备属性、酒馆收益、抽取晒卡、概率争议、奖励领取、活动任务、公会社交、充值消费、功能异常、登录性能、客服投诉、签到分享、攻略咨询、战斗竞技、数值平衡、资源道具、美术剧情、版本运营、退游流失、交易广告、简短互动、文字不足、社区闲聊。

议题独立于情感、风险等级和处理状态。评论只看自身正文，图片不送模型；纯图片标明文字不足。无效议题答案标为“议题待补判”，不得悄悄生成关键词分类或改变风险判定。现有完整 AI 议题保留。

补判范围为当前 BaaS 同步集合中已分析且 topics 为空、含“其他”或“议题待补判”的记录，不回溯尚未迁入后台的历史记录。按社区和正文哈希复用重复文本结果；每个请求至多十条独立题目，并发八。只更新 `po_analyses.topics`，更新前锁定内容及分析记录并校验指纹；写入前备份，写入后校验所有非议题字段哈希一致，记录审计，不调用告警或通知流程。

通过现有 BaaS snapshot/syncPage 接口同步变更内容，使用既有数据库命名锁隔离同步任务。失败保留进度和已成功的分类结果，下次可继续，不删除业务数据。

## 验收

验证分类边界、无效返回、批量索引、评论独立、风险判定不变、更新事务与回滚；使用真实模型做中文和海外样本检查，再补判。API 与正式浏览器检查超能世界、X-Clash、Last Light 的议题分布。说明补判数量、失败数和“其他”变化，代码不提交或推送 Git，不发布静态托管版本。
