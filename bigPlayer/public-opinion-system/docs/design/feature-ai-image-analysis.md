# 新增内容图片分析

Status: proposed
Updated: 2026-10-12

## 范围

后续进入 AI 分析链路的新增帖子、动态和评论，同时分析本条文字及本条图片。无图内容保持文字分析；不自动重判历史数据、不继承父帖图片。不修改风险等级定义。

## 推荐方案：全部图片低清优先，按需提高清晰度

1. 从既有 media 字段与正文图片链接提取本条有效图片，去重；不以固定前几张替代全部图片。
2. 优先使用现有网关中验证支持视觉的轻量模型。图片以低清模式读取，仅输出简短可见事实、关键文字及可读性，不重复生成完整风险判定。
3. 同一图片识别结果按图片身份、模型及提示词版本缓存；同批合并重复请求，light/deep 复用图片摘要。内容变化或缓存失效重新识别。
4. 默认最低图片细节；仅在低清结果明确不可读且可能影响问题核实的情况下，追加一次更清晰识别。费用设上限，不能把“最少 token”承诺为固定数值，实际以提供商 usage 为准。
5. 将经视觉模型观察的事实与原文明确分隔，参与既有情感、质量及风险判定。图片内容是待分析的数据，图内指令不能改变判定规则。看不清、加载失败不能被当作证据或被写成“已核验”。
6. 保留图片分析状态、数量、简短依据和实际 token 用量，支持详情复核；无需展示完整模型推理。

## 其他方案与取舍

- 全部图片固定低清：token 最低，但小字凭证和长截图容易漏读。
- 全部图片直接高清：读取更充分，但图片 token 显著增加，不符合低消耗优先要求。

## 异常与边界

只处理公开可访问且属于本条内容的图片。抓取限制类型、体积、超时与网络目标，拒绝本机及内网目标。图片不可访问、视觉模型不支持或额度不足时记录未完成状态，不能静默冒充完整图文分析。超长/多图内容分批，不静默截去后续图片。读取不了的关键证据留人工核实。

“魔塔没箱子”基准：图片确实显示宝箱时，只记录可见宝箱及位置；不能推测该层奖励规则，也不能据一句短描述断言奖励故障。图文无法核实明确问题时归关注，不因负面分数升级。

## 验证与交付

隔离测试覆盖图片提取、去重、缓存、light/deep 复用、失败与额度、文字图片证据隔离，以及小字按需升级。使用真实网关验证视觉能力与 usage，但不批量重判历史内容。可见浏览器检查图文详情及分析依据，接口检查状态与结果一致。完成最小必要检查、现役运行包核验后，仅提交推送本需求相关文件。
