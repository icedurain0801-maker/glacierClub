## 用户已确认的冲突处理

以用户 prompt 的最高优先级核心原则及串行决策树为准，不以情绪、分数、涉钱词、一般退款意向或热度单独升级。R1–R13 必须有本条原文或真实统计证据；低置信度非紧急降档，紧急保留交人工复核。用户授权真实 AI 重判北京时间 2026-10-11 超能世界国服版帖子和评论，更新结果但不补发历史通知。

## 互斥等级

| 关卡 | 结果 | 条件 |
|---|---|---|
| GATE0 | L0 / normal | 无可定位对象的泛吐槽、非目标产品、纯玩梗、明确已解决的历史复述、有真实去重证据的搬运、广告；正面攻略/正常无风险讨论兼容现有 normal 状态，不删除内容 |
| GATE1 | L1 / attention / 关注级 | 不具备可核查对象与具体可证伪说法；包括运气、审美、纯强度口水、普通咨询、无复现条件的个人一次闪退 |
| GATE2 | L3 / urgent / 紧急告警 | 已有实际问题，且验证 R1–R13 或有真实上下文的 U3–U5 |
| GATE3 | L2 / negative / 紧急告警（合并展示） | 已有实际问题，但不满足紧急条件 |

分数 >0.50 不再单独跨过 GATE1。帖子与评论各自判断，不继承父帖等级。只使用本条输入及明示上下文，不补全不可见截图、后果或聚集统计。

## 实际问题分界

L2 必须给出 <=20 字的问题概括，保存逐字存在于原文的 issue_object 和 claim_evidence。先检查同句概率/爆率/暗改/统计等例外词，再执行个人运气白名单降噪；例外只解除运气降档，普通概率咨询仍 L1。另一句明确故障不因同时出现运气抱怨而被降档。

基准：联盟 Boss 集结约每十次崩溃一次，重连耗时、战斗不同步，为可核查故障，判 L2；结尾问是不是手机问题不覆盖前面事实。中文/英文明确复现场景、奖励未到账等事实可纠正模型漏标的问题对象与概括；只修复原文事实，不依赖分数或模型摘要。假设、否定、已解决、教程排除。低置信按新规则降档并标抽检。

## 紧急条件与证据

| 编号 | 条件 |
|---|---|
| R1 | 指向产品的真实涉赌定性；玩梗/比喻情绪不算具体指控 |
| R2 | 未成年人消费并伴随监管、投诉或凭证 |
| R3 | 概率未按公示/未公示/公示不一致，有可读实证 |
| R4 | 实际外部投诉、律师函、媒体问询或具体法律行动；流程咨询不算 |
| R5 | 可复现错价、兑换错误、超发、无限领取等资损漏洞，有复现步骤或可读样本 |
| R6 | 账号被盗、数据/隐私泄露、异常扣款等安全事实 |
| R7 | 持续无法登录/游玩、群体中断、回档、维护超时；个人偶发不算 |
| R8 | 可指认的组织差评、集体退款、联名、举报接龙行动 |
| R9 | 已提供跨平台及 >=3 倍真实板块基线数据 |
| R10 | 已提供同问题 clusterCount>=50 |
| R11 | 已提供组织抹黑的核实上下文 |
| R12 | 数值/概率/掉落暗改指控，有可读实证 |
| R13 | 已实施投诉/退款/差评/媒体行动，有可读凭证 |

每个命中保存 rule_evidence 摘录，校验原文与规则特定表达。R9/R10/R11 及 U3（客服未解决后二次反馈）、U4（版更窗口）、U5（迁移/首页）须有真实 riskMetadata。字段缺失不构造；本次不新增聚类、跨平台采集、图片 OCR 或版本管理。

“见截图”不能算已核验图片；实证数组须与实际可读材料或可信 evidenceTypes 一致。文本复现步骤、公告原文、统计样本可校验。D1 仅有核实误读上下文时降 L1 并留澄清标记；D2 无事实指向的情绪停 L1。L3 不因低置信或深度分析自动降级，保存 downgrade_suggest；本次重判不继承历史旧算法 urgent。

## 协议与持久化

风险对象包含用户要求的 level、level_name、gate_result、claim_type、has_evidence、evidence_types、action_intent、hit_rules、whitelist_hit/override、need_clarification、downgrade_suggest、module、issue_summary、confidence、reason；增加 issue_object、claim_evidence、noise_reason、rule_evidence 供校验。补充编号 G1（未过问题闸）、G3（实际问题非紧急）、W1（运气白名单）有明确含义，不使用示例里未定义的 P1。

OpenAI 兼容接口以严格 JSON Schema 输出 `{results:[...]}`，minItems/maxItems 保证批次等长；解析仍兼容数组，Anthropic 按提示词输出数组。原情感/质量字段保留。light/deep 同一规则，prompt/cache 新版本隔离旧结果；缓存键包含实证与统计上下文。按输出 token 配额拆批避免截断，不替换模型、凭据或服务每日额度。

原始及校验后的决策随 rawAnalysis 进入既有 risk_context，事务审计保留旧分析。缓存/重复归一化可复核源句，显式当前正文优先；fingerprint 改变拒绝写入。本次不执行数据库迁移。
