# Facebook 图文采集与图片分析

Status: approved — 用户于 2026-10-20 弹窗确认。

所有 Facebook 网页来源采集帖子、评论与回复自身正文及附图；排除头像、图标和其他内容的附图。纯图片也进入分析。图片文字和可见画面作为独立识别证据保存，不改写用户原文；综合判级沿用当前社区规则及独立复核。图片读取或识别失败进入现有分析重试队列，不生成“正常”结论。

每轮使用北京时间昨天 00:00 至本轮开始时的固定时间范围，并保存至任务。正文、图片、评论、回复都遵循本内容自己的发布时间；原帖上下文单独处理，不继承原帖问题或图片。分页断点须绑定该范围，不能借用其他轮次。

现有 media JSON、分析原始结果、队列及详情组件优先复用；不迁移数据库。图片只读取 Facebook 官方 CDN 的 HTTPS 地址，限制字节数、类型及跳转；识别不执行图片中的指令。模型只接收图片和识别指令，不接收 Facebook 账密。

完成必要测试和真实浏览器验证后，按现役基线精确合入本任务文件，发布后执行一次已授权的 Last Light 同步，检查真实任务、图片和 AI 原因；不重跑其他社区历史数据。
