# Facebook 真实浏览器登录与采集会话复用

Status: 用户已确认方案，实施中

用户直接在真实 Facebook 网页完成登录和人工验证。网页登录没有业务回调，登录服务轮询自己持有的同一浏览器会话，通过 Facebook 页面状态及真实登录 Cookie 确认成功，随后使用原有账号授权与采集链路。

Windows 服务不能向用户桌面打开可操作窗口，因此增加用户桌面运行的本机浏览器启动器。启动器仅监听 127.0.0.1，使用既有内部鉴权；按来源与账号建立独立浏览器资料目录，返回仅限回环地址的 CDP 连接。账密仅由登录服务读取并填入真实 Facebook 页面，不经过前端或启动器。管理员入口增加“打开真实浏览器登录”，继续使用现有人工验证状态及刷新结果入口。

启动器未运行时明确提示，禁止退化为其他社区会话。外部浏览器关闭、配置版本变化或登录超时时不得标记成功；保留原有内嵌入口。启动器是本机配套进程，需要用户桌面处于登录状态，不安装为不可交互的 Windows 服务。

本次新增启动器、回环地址校验、登录服务接入、账号管理按钮及测试；不修改采集时间、图文分析和钉钉规则。真实同步仍限定 Last Light 一次，成功登录后才入队。切换前核对现役基线，发布授权在具体候选完成后确认。
