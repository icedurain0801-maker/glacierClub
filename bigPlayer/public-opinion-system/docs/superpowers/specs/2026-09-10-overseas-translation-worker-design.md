# 境外内容中文翻译工作器设计

## 目标

消费已由采集工作器写入 `po_translation_jobs` 的境外内容翻译任务，将原文标题和正文翻译为简体中文并保存到 `po_content_translations`，使内容详情可展示译文。

## 范围

- 新增独立的 `translationWorker` 常驻进程。
- 复用既有 `AI_TRANSLATION_*` 配置；未启用或未配置服务时不领取任务。
- 成功时保存译文并将任务置为 `completed`。
- 可恢复错误置为 `retryable` 并按已有退避配置重试；达到最大尝试次数或配置错误时置为 `failed`。
- 启动时及每轮扫描时补入缺失的境外翻译任务，以处理已积压内容。

## 数据流

`worker.js` 采集内容并入队 → `translationWorker.js` 领取任务 → 翻译服务 → `po_content_translations` → `po_translation_jobs` 状态完成 → 内容详情展示译文。

## 错误处理

- 翻译服务超时、限流和服务端错误：按指数退避重试。
- 缺少翻译服务配置、无有效输入或返回内容为空：记录明确错误码，避免任务无限运行。
- 使用任务租约所有者完成状态更新，避免并发工作器覆盖结果。

## 验证

使用单元测试验证成功落库、可重试失败、最终失败、未启用时不消费任务，以及工作器脚本入口存在。
