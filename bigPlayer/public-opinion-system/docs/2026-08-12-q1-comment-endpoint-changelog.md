# Q1 H5 评论接口适配变更

日期：2026-08-12

## 变更内容

- 根据 `club.q1.com` 公开前端懒加载 chunk，确认评论读取接口为：
  - `GET /api/club/v1/auth/comment/:postId`
  - 顶层评论传 `commentId` 为空；评论内回复传具体 `commentId`
  - 分页参数为 `offsetId`、`pageSize`
  - 排序参数为 `sortType`，前端使用 `0`（默认）、`1`（最新）、`2`（最早）
  - 响应结构为 `{ data: [], total }`
- H5 连接器新增 Q1 顶层评论和回复分页适配。
- Q1 评论游标保存 `offsetId/sortType/commentId`，与现有断点续采契约兼容。
- Q1 评论映射为深度 1，回复映射为深度 2，并保留根帖子 ID、直接父评论 ID、作者和删除/隐藏状态。
- Q1 源的评论能力不再硬编码为 `unsupported`；仍需通过账号凭据和实际请求完成授权探测。
- 所有请求继续使用账号级凭据、环境白名单、手动重定向拒绝和结构化错误分类。

## 验证

- 连接器定向测试：12/12 通过。
- public-opinion-system server 与 worker 测试：126/126 通过。

## 未完成及边界

- 公开前端代码只能证明消费端请求契约，不证明当前账号具备评论历史全量授权。
- 真实 Q1 请求可能还需要页面运行时维护的 `Secret` 或其他会话上下文；本轮未绕过认证、验证码或访问控制。
- 在真实授权联调和断点恢复验收前，不将生产同步状态标记为 `completed_full`。
