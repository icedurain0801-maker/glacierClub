# v145 六页共享 Scope 真实浏览器验收清单

- 状态：待开发交付。
- 验收方式：仅真实浏览器；不以 Mock、API 200 或静态测试替代。

| 编号 | 验收项 | 通过标准 |
| --- | --- | --- |
| 1 | 六页入口 | 六个页面均加载共享地区/社区 Scope，页面无白屏或脚本错误。 |
| 2 | 即时刷新 | 切换地区或社区后，当前页数据立即按新 Scope 刷新。 |
| 3 | 跨页继承 | 页面间跳转后地区、社区和 URL 参数保持一致。 |
| 4 | 会话与导航 | 刷新、前进、后退后 Scope 与页面数据一致，session 状态不覆盖 URL 的有效选择。 |
| 5 | 无效回退 | 无效或已禁用社区自动回退到可用状态，且无无效请求。 |
| 6 | 无社区空态 | 无可用社区时展示合法空态，不发缺失或错误 communityId 的请求。 |
| 7 | 独立筛选 | Scope 变化时清除不适用于新 Scope 的页面独立筛选，并保留仍合法的筛选。 |
| 8 | 请求范围 | 六页各自 API 请求均带正确的 regionCode、gameId、communityId 和适用平台 Scope。 |
| 9 | 快速切换 | 连续快速切换 Scope 后，仅最后一次选择的数据可见，旧响应不得覆盖。 |
| 10 | 控制台 | 六页交互全过程无 `error` / `warn`。 |
