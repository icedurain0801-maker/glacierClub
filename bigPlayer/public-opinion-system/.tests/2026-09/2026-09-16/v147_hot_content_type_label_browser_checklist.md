# v147 负面热帖类型标签真实浏览器验收清单

- 状态：待开发交付。
- 门禁：仅真实浏览器 PASS 与最终报告可关闭。

| 验收项 | 通过标准 |
| --- | --- |
| BigPlayer 类型 | `type=0` 显示帖子，`type=1` 显示动态；不以标题是否为空判断。 |
| 其他社区 | 非 BigPlayer 保持既有内容类型口径。 |
| 类型覆盖 | 帖子、动态、评论三类标签均可见且与“全部内容”对应记录类型一致。 |
| 展示回归 | 标签样式、热帖排序、标题、摘要、查看与全部内容入口无回归。 |
| 概览标题 | 模块中文标题必须为“概览”，全页面不得出现“今日概览”；`KEY METRICS`、时间范围、四卡数据及其他文案不变。 |
| 最终双列 | “内容与议题”仅保留左右并列的“负面内容”和“关注级内容”；议题分布及聚类说明完全移除。 |
| 双列同源 | `negative` / `attention` 各自与四卡、全部内容落地页同源；按互动量降序，内容实际类型标签、标题摘要、详情入口一致。 |
| 双列范围 | 两列随时间范围与共享 Scope 同步；各自空状态正确，深链完整并清除旧定位参数。 |
| 双视口 | 桌面与 `375x812` 中两列样式和交互一致、无重叠、裁切或页面级横向溢出。 |
| 稳定性 | 页面/API 正常，控制台无 `error` / `warn`。 |
