### 缺陷 1：Token 已配置且历史起点留空时，普通配置无法保存

复现步骤：

1. 打开上述本地 3000 页面，选择境内 / 超能世界国服版 / BigPlayer社区。
2. 在唯一“大玩家H5社区”行点击“管理”。
3. 确认授权方式为“Token”，已有 Token 显示“已配置；留空保持不变”；普通 BigPlayer 配置未要求填写历史起点。
4. 不修改字段，直接点击“保存配置”。

预期：配置保存成功，不出现“历史回溯必须填写历史起点”。

实际：保存失败，页面 toast 显示：`保存失败：基础配置保存失败：syncMode must be incremental or backfill`。

可见证据：失败 toast 已在浏览器截图中保留；抽屉仍停留在配置页，Token 面板可见且未要求历史起点。
