## 缺陷

### P1：TapTap 抽屉缺少原验证区和双列布局

复现：境内 / 超能世界国服版 → 数据平台 TapTap → 管理。

实际：抽屉展示“采集频率”“TapTap 网页地址”“同步控制”，并显示“Token 授权无需登录会话验证”说明；没有交接文档要求保留的原验证工作区与双列布局。

期望：TapTap 等其他平台保持原验证区和双列布局，不受 BigPlayer Token 单列改动影响。

处理：退回开发负责人修复后重新进行真实浏览器回归。

2. 未在 TapTap 页面执行任何保存、检测、同步或凭据操作。
