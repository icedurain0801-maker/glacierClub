## 重要设计决策

### 2026-04-07 — 徽章奖励体系（v3.0.9）
- **背景**：徽章引入奖品绑定功能，与 admin 端 BadgeManage.html 同版本联动
- **决策**：徽章图标左上角新增 🎁 礼包 icon 标识有奖励的徽章
- **奖励展示**：详情页（s4）佩戴按钮上方新增奖励展示区，深色半透明卡片；通知弹窗（s5）使用亮色 pill 标签展示
- **领奖流程**：仅头像框 → 直接获得；含道具 → 跳转角色信息确认（s6）
- **领奖入口**：徽章左上角显示 🎁 icon，点击进入 s4，再点击「领奖」

### 2026-04-07 — 多屏 Hash 路由
- **背景**：需要支持从外部直接链接到特定屏幕（如通知站内信跳转）
- **决策**：在 `initSidebar` 后追加 `_applyHash` 函数，监听 `hashchange` 事件
- **用法**：`Badge.html#s5` 直接展示第5屏

### 徽章形状区分
- **决策**：活跃成就类用五边形（五角星形），社交影响和互动传播类用圆形，以形状区分徽章类型
- **展示槽**：用六边形空槽代表未填入的展示位

## 技术备注

- Tailwind CSS 通过 CDN 引入，不使用本地构建，Tailwind 配置均为默认
- `clip-path` 涉及的伪元素样式（如 s4 的光晕效果）用独立 `<style>` 块补充
- 屏幕间跳转通过 `fromScreen` 变量记录来源，使返回逻辑动态化（s4 可能从 s1/s2/s3 进入）
- 右侧文档面板的版本折叠逻辑：默认最新版展开（`.doc-version-body` 不加 `hidden`），旧版折叠（加 `hidden`）
- 图片资源（如头像）使用外部 CDN，离线状态不可用
