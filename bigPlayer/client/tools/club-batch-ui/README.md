# Club Batch UI

本工具用于本地批量账号自动化操作（登录 / 点赞 / 评论 / 发帖），带网页界面。

## 启动

1. 确认当前机器可运行 `node`，且已安装 `playwright`。
2. 在本目录执行：

```powershell
node server.js
```

或直接双击：

```text
start.bat
```

3. 打开界面：`http://127.0.0.1:3777`

## 账号格式

在“账号列表”里每行一个账号：

```text
账号,密码
```

示例：

```text
dbpei005,123456
dbpei006,123456
```

## 功能

- 并发登录（并发数可配）
- 每号点赞次数可配
- 每号评论次数可配
- 每号发帖次数可配
- “尽量不同帖子”模式
- 验证码出现时，在账号行直接输入并提交
- 实时查看每个账号执行日志与成功计数
