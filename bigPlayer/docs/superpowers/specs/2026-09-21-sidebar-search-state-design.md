# 侧边栏搜索状态保留设计

## 目标

用户在侧边栏输入搜索词并点击搜索结果跳转页面后，输入内容、筛选结果和侧边栏滚动上下文保持不变，便于连续查看同一批搜索结果。

## 已确认方案

采用 `sessionStorage` 保存搜索词：

- 状态仅在当前浏览器页签内有效，不跨页签、不跨浏览器会话长期残留。
- 输入内容非空时，实时写入 `sidebar.searchQuery`。
- 页面初始化时读取该值，恢复输入框并重新渲染相同的搜索结果。
- 所有引用共享侧边栏的页面统一使用同一脚本版本标识，避免页面跳转后命中旧缓存并丢失恢复逻辑。
- 点击搜索结果只执行页面跳转，不清空搜索词，也不恢复完整目录树。
- 用户主动将输入框清空后，删除 `sidebar.searchQuery`，隐藏搜索结果并恢复完整目录树。
- 侧边栏滚动位置继续使用既有 `sidebar.scrollTop` 机制，不新增第二套滚动状态。
- 当内嵌预览环境不开放 Web Storage 时，使用 `window.name` 镜像搜索词；其生命周期与当前浏览器页签一致，不写入 URL，也不跨页签传播。

## 异常处理

当浏览器禁用或拒绝访问 `sessionStorage` 时，自动使用同页签 `window.name` 镜像继续保留搜索状态；两种存储均不可用时，才降级为仅在当前页面有效。

## 验收标准

1. 输入 `3.1.4` 后展示匹配结果。
2. 点击任一搜索结果进入新页面后，输入框仍为 `3.1.4`，匹配结果列表保持展示。
3. 侧边栏滚动位置不因页面跳转复位。
4. 清空输入框后恢复完整目录，并且后续页面不再恢复旧搜索词。
