# 大玩家系统

## 目录结构

```
bigPlayer/
├── client/                  # C端（移动端用户）
│   ├── home/                # 首页
│   ├── news/                # 资讯
│   ├── circle/              # 玩家圈
│   ├── profile/             # 我的
│   └── post-detail/         # 帖子详情
│
└── admin/                   # 后台管理系统
    ├── content-management/  # 内容管理
    ├── community/           # 社区功能
    ├── user-management/     # 用户管理
    ├── log-management/      # 日志管理
    ├── analytics/           # 数据分析
    └── section-management/  # 版块管理
```
