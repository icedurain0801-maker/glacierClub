# 限时任务条件逐项规则补全

日期：2026-09-22  
状态：已确认，未发布

## 变更内容

限时任务管理的需求说明将原有按任务大类汇总的四行规则，改为十个可选任务逐项说明。每项明确计数对象、活动期范围、历史行为是否计入与重复计数边界。

- 浏览创作：仅统计活动期新增浏览，历史浏览不计。
- 浏览指定帖子：存在任一历史有效浏览记录即可完成，可早于活动开始。
- 创作被浏览：仅统计活动期内玩家本人帖子或动态新增获得的浏览，评论不计。
- 指定帖评论、指定帖点赞及其余数量型任务：仅统计活动期内新增的有效行为，历史行为不计。

## 审查结论

已覆盖活动期计数、历史行为例外、玩家与内容去重、取消点赞不回退，以及帖子/动态与评论的统计边界。事件延迟、删除或撤回后的最终计数仍按现有待确认项处理。
