# v001 变更记录

## 创作任务管理原型（v3.1.4）

- 新增 CreationTaskManage.html：以攻略组管理页面为交互和视觉基底，提供任务列表、审核列表、筛选、任务启停、复制和新增任务侧边栏。
- 在“后台管理 → 社区功能”中新增“创作管理 → 创作任务管理”导航入口，位置位于“攻略站管理”之后。
- 新页面右下角保留“需求说明”入口与侧边面板，说明正文按要求保持为空。
- 新增奖励类型配置：默认经验值；可切换为游戏道具或个性装扮。游戏道具支持“道具选择 + 数量 + 添加 + 多标签删除/清空”，个性装扮支持“头像框/个性背景 + 装扮选择 + 添加”。
- 已将本次新增的奖品类型、奖励字段、联动规则、数量必填校验和待确认业务口径写入页面右下角「需求说明」。
- 游戏道具添加后，奖励标签展示对应的道具 ICON；道具无 ICON 或 ICON 加载失败时，统一展示裂图 ICON 占位。
- 需求说明补充道具 ICON 字段、读取来源、20px 展示规格及空地址 / 加载失败的裂图占位规则。
- 增加单项任务奖励类型互斥规则：经验值、游戏道具、个性装扮不可混合；已添加道具或装扮后须先清空，才可切换奖励类型。

## 社区货币管理

- 在“后台管理”中新增“客服管理 → 社区货币管理”导航，位置位于“版块管理”之后。
- 新增 CommunityCurrencyManage.html：提供正式列表与审核列表 Tab、通行证 / 类型 / 状态 / 操作人筛选、分页、审核流转与新增赠送抽屉。
- 发放仅支持经验值、头像框和个性背景；所有发放均为赠送，表单不提供扣除或负数数量入口。
- 右下角保留空白的“需求说明”侧边栏，等待后续填充。
- 修复社区货币管理页左侧导航容器漏用深色侧栏样式导致的低对比度问题。
- 任务设置固定为单行列模型（排序、任务类型、达成要求、奖励、操作）；桌面侧边栏按固定列宽分配，窄视口改为整表横向滚动，避免控件重叠或越界。
- 社区货币赠送支持添加多个通行证ID，并提供手动添加、Excel 导入和 Excel 模板下载入口；抽屉内以校验表展示通行证ID、通行证名称和账号存在性结果。重复ID不可重复添加，账号不存在时不可提交审核。
- 新增 CommunityCurrencyImportTemplate.xlsx，模板仅包含“通行证ID”导入列，并将该列设为文本格式以避免通行证ID显示为科学计数法。
- 发放类型统一为“经验值、个性装扮”两类；个性装扮的发放内容明确展示“头像框 / 个性背景 + 装扮名称”。
- 正式列表状态统一为“审核通过、审核拒绝”，审核列表增加状态列且固定为“待审核”；审核通过或驳回后均流转至正式列表。
- 发放类型标签移除“赠送”前缀，仅展示“经验值”或“个性装扮”。
- 完善社区货币管理页右下角「需求说明」：按列表筛选项、正式列表字段、审核列表字段、赠送字段、规则说明及待确认口径补充完整字段字典，明确是否必填、默认值、模糊/精确匹配方式和校验规则。
- 社区货币管理页「需求说明」侧栏宽度由480px调整为960px；窄视口仍限制为屏幕宽度。
- 社区货币管理页「需求说明」的正式列表字段表移除冗余的“是否必填”列，并收窄表格最小宽度。
- 社区货币管理页 Excel 导入文件大小上限由2MB调整为100MB，并同步更新需求说明与前端校验提示。
