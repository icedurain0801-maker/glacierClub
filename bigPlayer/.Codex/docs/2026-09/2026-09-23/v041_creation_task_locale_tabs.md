# v3.1.4 创作任务海外语种配置

日期：2026-09-23

## 变更内容

- 创作任务列表、审核列表及新增创作任务抽屉的海外版块选项补充 `Last Light`、`X-clash`。
- 新增创作任务时，表单继承列表当前所属版块：海外版块显示语种配置区，国内版块不显示。
- 海外语种配置默认英文，可添加繁体中文、日文、韩文等语种；英文作为兜底语种保留。

## 规则

- 海外版块范围：`Saint Soul Strife`、`Super World`、`Titan's Fall`、`Eternal Bonds`、`Last Light`、`X-clash`。
- 所属版块为国内时，创作任务按单语言配置；所属版块为海外时，使用多语种内容配置。
- 新增抽屉打开时必须根据当前列表所属版块完成语种区初始化，避免用户未再次切换筛选条件时缺失语种配置。
