# v001 变更记录

- 左侧导航“后台管理 → 客服管理 → 社区货币管理”新增版本标记 `v3.1.4`。
- 社区货币管理需求说明标题新增版本号 `v3.1.4`；审核列表字段规则表移除冗余的“是否必填”列。
- 新增「社区功能 → 限时任务管理 → 限时任务列表」入口与 `admin/community/TimedTaskManage.html` 页面（v3.1.4），包含任务列表、审核列表、新增限时任务抽屉及与创作任务一致的经验值、游戏道具、个性装扮奖励交互。
- 同步限时任务已确认的任务类型、奖励互斥规则和后续待确认口径至大玩家需求审查基线。
- 限时任务开始/结束时间方案画廊补充组件展开态，六个方案分别展示日历、时刻、区间和快捷选项展开层，便于确认实际占用空间。
- 用户确认采用方案 2；限时任务新增抽屉改为开始/结束时间轴布局，时间输入支持秒级精度并校验结束时间晚于开始时间。
- 用户确认采用方案 4；抽屉关闭入口改为“取消新建”，任务选项去除 `x` 占位符，已有输入退出时增加二次确认并在确认后清空草稿。
- 数量型任务统一按“次数”配置与展示，移除“篇数”单位并同步更新任务选项、输入提示、单位和列表示例。
- 根据用户确认，新增任务抽屉右上角关闭入口恢复为标准 `×` 图标，保留取消退出时的草稿二次确认逻辑。
- 限时任务新增支持 1–4 组“任务+奖励”，每组可独立配置任务大类、任务类型、次数/目标要求和奖励类型；提交时逐组校验并将各组任务与奖励合并展示。
- 浏览/评论/点赞的指定帖子任务增加帖文 ID 即时校验：有效帖子或动态显示绿色对号及文本前 10 个字符（无文字动态仅显示对号），无效 ID 显示红色“帖文不存在”。
- 限时任务审核列表增加批量审核：支持全选/多选待审核任务，统一选择通过或拒绝并填写 50 字审核备注，提交后批量更新状态和审核信息。
- 用户确认限时任务 4 组任务+奖励独立执行、每组完成后立即发放对应奖励；指定帖子校验失败时禁止提交审核。
- 汇总用户确认的限时任务规则至页面需求说明：用户范围、北京时间与时间冲突校验、按玩家/内容去重的行为计数、取消点赞不扣减、内容失效后的计数、奖励补发、任务删除/审核、C 端展示、完成率和永久操作记录等；保留真实校验接口及时间边界等待确认事项。
- 限时任务需求说明侧栏宽度由 `480px` 调整为 `960px`，窄屏仍按视口宽度自适应。
