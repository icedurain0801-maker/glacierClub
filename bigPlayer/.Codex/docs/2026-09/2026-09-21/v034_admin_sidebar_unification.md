# Admin 侧边栏统一

日期：2026-09-21

状态：已完成

## 变更内容

1. 所有 admin 页面统一使用与 `WelfareTask.html` 一致的固定左侧共享导航样式、完整导航目录和搜索入口。
2. 取消舆情模块的专用侧栏分流，保留其页面内业务功能与范围参数传递逻辑。
3. 官网展示页接入共享侧栏，并在「后台管理 → 内容管理」中增加“官网展示”导航入口。
4. 所有 admin 页面统一引用 `admin-sidebar-v034` 版侧栏资源，避免旧缓存造成侧栏未固定或样式不一致。
5. `changelog.html` 同步接入该固定侧栏，并为主体预留 250px 左侧空间。

## 验收范围

- 任一 admin 页面均展示相同的品牌、搜索框、目录结构和侧栏视觉样式。
- 当前页面在共享目录中保持正确高亮；舆情页面跳转继续传递既有范围参数。
