# 大玩家与舆情分析侧边栏隔离

## 问题

- 共享侧边栏脚本被异常覆盖，导致 `initSidebar()` 不存在，大玩家页面只剩空白侧栏背景。
- C 端固定侧边栏的页面位移规则错误命中舆情页面，造成舆情侧栏左侧出现额外空白。

## 修复

- 恢复侧边栏完整渲染、搜索、当前项高亮和滚动位置记忆逻辑。
- 通过页面路径严格区分大玩家与舆情分析系统的导航数据、Logo、样式类和状态存储键。
- 大玩家侧边栏使用 `sidebar--fixed-left`；舆情分析仅使用 `sidebar--public-opinion`，不再继承 C 端页面位移。
- 搜索状态只在大玩家侧边栏启用，舆情分析侧边栏不创建搜索控件。

## 验收口径

- 福利任务页显示“大玩家”Logo、搜索框和完整目录，当前“福利任务”页签高亮。
- 舆情概览页显示“舆情分析系统”Logo和 6 个专属导航项，不显示大玩家目录或搜索框。
- 两套系统的搜索状态、滚动位置和布局互不影响。
