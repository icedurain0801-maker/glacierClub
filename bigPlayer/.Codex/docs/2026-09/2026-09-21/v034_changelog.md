# 侧边栏搜索状态跨页面保留

## 变更内容

- 使用 `sessionStorage` 保存当前浏览器页签内的侧边栏搜索词。
- 为禁用 Web Storage 的内嵌预览环境增加同页签 `window.name` 镜像兜底。
- 点击搜索结果跳转页面后，自动恢复输入内容和筛选结果。
- 统一刷新 35 个侧边栏页面的共享脚本缓存版本标识。
- 保留既有侧边栏滚动位置记忆，不因搜索结果跳转重置。
- 用户清空输入框时删除搜索记录，并恢复完整目录树。
- 存储不可用时降级为当前页面搜索，不影响侧边栏导航。

## 验收范围

- 搜索 `3.1.4` 后连续打开多个匹配页面，搜索词与结果列表保持不变。
- 清空输入框后刷新或跳转页面，不再恢复旧搜索词。
