# v3.1.4 综合需求说明收口

日期：2026-09-21

状态：已完成

## 变更内容

将原先分散展示的福利任务入口、福利任务页限时任务和首页发帖话题推荐，统一收口为首页「v3.1.4 综合需求说明」。

综合说明覆盖以下规则：

1. 板块管理“功能栏”配置与福利任务入口在首页顶部、侧边栏之间的互斥迁移。
2. 福利任务页的展示顺序、限时任务类型、指定对象跳转、奖励展示、失效处理和奖励幂等。
3. 首页发帖推荐话题的数量限制、卡片展示、勾选状态和进入两类发布页时的自动带入。
4. 跨页面联动验收，包括入口配置切换、任务完成/过期、对象失效及话题带入。

福利任务页保留为专项执行细则，标题调整为「v3.1.4 综合需求说明 · 福利任务专项」，避免与首页综合说明形成两个“最新版本”的并列口径。
