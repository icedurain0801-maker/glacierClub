# 大玩家社区工具台 — 设计文档

**日期：** 2026-06-30  
**归属目录：** `operations/communityTools/`  
**状态：** 待实现

---

## 概述

独立工具页（不套用运营后台 shell），供运营人员完成两类任务：

1. 生成社区跳转链接（Deep Link / H5 分享链接）
2. 排查用户问题和链接异常

页面内嵌 AI 机器人，以**结果输出**形式呈现，不做对话交互。

---

## 页面结构

三页路由，单 HTML 文件内用 JS 切换显示：

```
首页（入口选择）
├── 链接生成器
└── 错误排查
```

顶部固定 header，含 Logo、标题、面包屑导航（子页展示，点击回首页）、内部工具角标。

---

## 首页

两张工具卡片横排，点击进入对应子页：

- **链接生成器**：标签 Deep Link / H5 分享链接 / 参数校验
- **错误排查**：标签 用户问题 / 链接异常 / AI 诊断

页面底部附 AI 辅助说明条。

---

## 链接生成器

### 表单字段

| 字段 | 类型 | 选项 | 默认值 |
|------|------|------|--------|
| 社区类型 | 单选按钮组 | 游戏内嵌 / 网页 / 小程序 / APP | 游戏内嵌 |
| 部署环境 | 单选按钮组 | 正式服 / 测试服 | 正式服 |
| 发行地区 | 单选按钮组 | 境内 / 境外 | 境内 |
| 游戏类型 | 单选按钮组 | 官方发行 / 渠道联运 | 官方发行 |
| 链接类型 | Tab 切换 | App 内跳转（Deep Link）/ H5 分享链接 | Deep Link |
| 定位到指定帖子 | Toggle 开关 | 开启后展示板块 ID + 帖子 ID 两个文本输入框 | 关闭 |
| 备注 | 文本输入 | 可选，便于追溯 | 空 |

社区类型、部署环境、发行地区三组单选横排一行（三列网格）。

### AI 输出区

点击「生成链接」后，AI 输出区展示：

- 生成的链接字符串（monospace 字体，可复制）
- 「复制链接」「测试跳转」操作按钮
- AI 参数校验摘要（参数合法性、目标资源是否存在、生成时间戳）

---

## 错误排查

### 两种模式（Tab 切换）

**用户问题排查：**

| 字段 | 类型 | 说明 |
|------|------|------|
| 用户 ID | 文本输入 | UID 或手机号，必填 |
| 平台 | 下拉选择 | iOS / Android / 全部 |
| 问题描述 | 多行文本 | 必填，描述用户反馈现象 |

**链接异常排查：**

| 字段 | 类型 | 说明 |
|------|------|------|
| 待检测链接 | 文本输入 | Deep Link 或 H5 链接，必填 |
| 异常现象 | 下拉选择 | 点击无反应 / 跳转空白 / 404 / 参数丢失 |
| 发现时间 | 文本输入 | 可选 |

### AI 输出区

点击「开始排查」后，AI 输出区展示三个层级的结果卡片：

1. **可能原因**（黄色标记）：置信度百分比 + 原因描述
2. **建议操作**（绿色标记）：有序排查步骤列表
3. **需人工确认**（红色标记）：人工介入提示
