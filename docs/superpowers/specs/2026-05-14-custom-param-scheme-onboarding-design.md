# 自定义参数方案流程引导 — 设计文档

**日期：** 2026-05-14  
**目标：** 在不改变现有操作路径的前提下，让新用户能看懂「先建参数 → 再建方案」的两步前置流程；老用户可一键永久隐藏引导，不受影响。

---

## 背景

自定义参数方案的创建依赖提前在「参数管理」中建立参数，但现有页面没有任何提示，新用户进入「新增方案」表单后，参数列表为空，只显示「暂无数据」，不知道下一步应该怎么做。

---

## 方案选择

选定**方案 A：分步引导横幅 + 空状态改造**，理由：
- 改动范围最小，只涉及 HTML/CSS/少量 JS，不重构现有交互逻辑
- 老用户可「不再显示」，写入 localStorage 后永久隐藏
- 引导出现在用户最需要的两个时机：进列表页 & 参数为空时

---

## 涉及文件

| 文件 | 改动内容 |
|------|----------|
| `SDK/admin/schemeManagement/specialScheme.html` | 改动 1：顶部引导横幅 |
| `SDK/admin/config/configCreate.html`（新增参数方案表单页） | 改动 2：参数为空时的引导卡片 |
| `SDK/admin/config/configList.html`（参数列表页） | 无改动（被链接跳转的目标页） |

> 页面关系：`specialScheme.html` 是自定义参数方案列表页；点「新增」后进入 `configCreate.html`；参数管理入口为 `configList.html`。

---

## 改动 1：列表页顶部引导横幅

### 位置
自定义参数方案列表页（`specialScheme.html`）的内容区最顶部，位于搜索栏和按钮行之上。

### 样式
- 背景色：`#eff6ff`（蓝色浅底），底部边框：`1px solid #bfdbfe`
- 高度：约 42px，单行布局
- 左侧：两步图示，文字形式
  - `① 在「参数管理」中新建参数` — 「参数管理」为蓝色下划线链接，点击跳转参数列表 tab
  - `→`（分隔箭头）
  - `② 回此页「新增」方案，从参数中选值`
- 右侧：两个操作按钮
  - `不再显示`：小号边框按钮，点击后 `localStorage.setItem('hideParamSchemeGuide', '1')`，横幅永久隐藏
  - `×`：图标按钮，仅本次关闭（不写 localStorage）

### 显示逻辑
```js
// 页面加载时判断
if (localStorage.getItem('hideParamSchemeGuide') === '1') {
  document.getElementById('param-guide-banner').style.display = 'none';
}
```

### 文案
> ① 先在 **参数管理** 中新建参数　→　② 回此页点「新增」，选择参数并填写对应值

## 改动 2：新建方案时参数列表为空的引导卡片

### 触发时机
在新增方案表单中，参数列表区域（原「暂无数据」空状态）无已选参数时显示。

### 替换内容
将原有空状态 `<div>暂无数据</div>` 替换为引导卡片：

**卡片内容：**
- 标题：「还没有可用的参数」（字重 600，深蓝色）
- 说明文字：「创建方案前，需要先在「参数管理」中建立参数。建完后回来，在此处选择并填入对应的值。」
- 按钮：「前往参数管理 →」（蓝色实心按钮，点击跳转参数管理 tab/页面）

**样式：**
- 容器：蓝色虚线边框（`1.5px dashed #93c5fd`），背景 `#eff6ff`，圆角 8px，内边距 24px，居中对齐
- 按钮：`background:#2563eb; color:white; padding:7px 18px; border-radius:6px`

### 显示逻辑
`configCreate.html` 加载后检查参数列表区域是否为空（DOM 中参数行数量为 0），为空则显示引导卡片，不为空则隐藏。

---

## 不在此次范围内

- 参数管理页本身的改动
- 向导式流程重构
- 后端接口变更

---

## 验收标准

1. 新用户首次进入自定义参数方案列表页，能看到引导横幅
2. 点击「×」后横幅消失，刷新页面重新出现
3. 点击「不再显示」后横幅消失，刷新、重开浏览器均不再出现
4. 点击「参数管理」链接能正确跳转
5. 进入新增方案表单，参数列表为空时显示引导卡片，卡片中「前往参数管理」按钮可跳转
6. 参数列表有数据时，引导卡片不显示
