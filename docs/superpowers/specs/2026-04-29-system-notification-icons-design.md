# 系统通知图标区分设计

**日期：** 2026-04-29  
**文件：** `bigPlayer/client/home/notifications.html`（`#screen-system` 部分）

## 问题

系统通知列表所有条目图标视觉一致（均为蓝色铃铛渐变），无法区分正面/负面通知，用户扫一眼看不出哪条是好消息、哪条是警告。

## 设计方案

### 通知类型与图标对照

| 通知类型 | Emoji | 图标容器背景色 |
|---------|-------|--------------|
| 成就达成 | 🏆 | 浅蓝渐变 `linear-gradient(135deg, #e3f2fd, #bbdefb)` |
| 等级升级 | ⬆️ | 浅蓝渐变 |
| 被关注   | 👤 | 浅蓝渐变 |
| 帖子置顶 | 📌 | 浅蓝渐变 |
| 帖子删除 | ⚠️ | 浅橙渐变 `linear-gradient(135deg, #fff3e0, #ffe0b2)` |

### 视觉规则

- **正面通知**：图标容器用浅蓝渐变（`#e3f2fd → #bbdefb`），传达轻松积极感
- **负面通知**：图标容器用浅橙渐变（`#fff3e0 → #ffe0b2`），⚠️ emoji 自带警示感，语气克制不刺眼（比红色更温和）
- **图标尺寸**：容器 `44×44px`，圆角 `11px`，emoji `font-size: 20px`
- 未读行背景保持现有的 `#f0f7ff` 高亮逻辑不变

### 未覆盖的类型（当前页面中有）

现有 `#screen-system` 还包含"帖子审核通过"、"获得奖励"、"功能更新"——这些属于正面/中性通知，沿用浅蓝容器，图标建议：

| 通知类型 | Emoji |
|---------|-------|
| 帖子审核通过 | 📋 |
| 获得奖励（积分） | 💰 |
| 功能更新通知 | 📣 |

## 实现范围

仅修改 `notifications.html` 中 `#screen-system` 内各通知行的图标 `div`：
- 将现有 emoji + 彩色渐变背景替换为上表图标和标准化两种容器色
- 不改动布局、字体、已读/未读逻辑、其他 screen
