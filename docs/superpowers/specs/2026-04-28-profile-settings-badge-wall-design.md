# 个人中心：设置按钮 + 徽章墙设计文档

**日期：** 2026-04-28  
**文件：** `bigPlayer/client/profile/profile.html`  
**状态：** 待实现

---

## 需求背景

当前个人中心 header 区域（蓝色渐变 hero）左上角和右上角均为空，缺少两个功能入口：
1. **设置按钮** — 右上角
2. **徽章墙入口** — 用户名下方

---

## 设计方案：方案 A · Hero 内嵌胶囊条

### 设置按钮

- **位置：** hero 区右上角，与状态栏同高（`top: ~21px, right: 10px`）
- **样式：** 圆形图标按钮，28×28px，`background: rgba(255,255,255,0.22)`，`backdrop-filter: blur(8px)`，白色半透明边框
- **图标：** Material Symbols `settings`（或 ⚙ 等价）
- **颜色：** 白色图标
- **交互：** 点击跳转设置页

### 徽章胶囊条

位于头像区中心块，层级：头像 → 用户名 → 徽章胶囊，纵向排列，均水平居中。

#### 有徽章状态

- **形态：** 横向胶囊，`background: rgba(255,255,255,0.20)`，`backdrop-filter: blur(10px)`，白色半透明边框，圆角 20px
- **内容：** 最多展示 4 枚徽章小圆形图标（16×16px，各带彩色背景 + 白色描边）+ 右侧「+N ›」文字（剩余数量）
- **徽章图标：** 圆形，每枚独立背景色（暖色系，如 `#ffe5b4` / `#e0f7fa` 等）
- **交互：** 点击展开全屏徽章墙弹层

#### 零徽章空状态

- **形态：** 同胶囊样式，但透明度略低（`background: rgba(255,255,255,0.16)`）
- **内容：** 🔒 + 文字「还没有徽章，去解锁 ›」
- **文字颜色：** `rgba(255,255,255,0.85)`，字号 8.5px（原型缩放比例下）；实际 375px 宽度约 11px
- **交互：** 点击跳转徽章说明/解锁引导页

## 布局层级（hero 区内部结构）

```
hero (height: 208px, 蓝色渐变)
├── castle SVG 背景（opacity: 0.15）
├── 状态栏（顶部）
├── 设置按钮（右上角，绝对定位）
└── hero-center（绝对定位，bottom居中）
    ├── 头像（72×72px，带爪印角标）
    ├── 用户名行（文字 + 编辑图标）
    └── 徽章胶囊（有徽章 / 空状态 二选一）
```

---

## 状态逻辑

| 条件 | 渲染 |
|------|------|
| 用户徽章数量 = 0 | 空状态胶囊：🔒 + 引导文案 |
| 用户徽章数量 ≥ 1 | 有徽章胶囊：最多4枚图标 + `+N ›`（N = 总数 - 4，若 ≤ 4 枚则不显示 `+N`） |
