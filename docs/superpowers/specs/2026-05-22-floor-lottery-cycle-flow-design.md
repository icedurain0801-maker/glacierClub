# 楼层抽奖（含周期活动）流程规则设计

**日期**：2026-05-22
**模块**：`bigPlayer/admin/community/FloorLotteryManage.html`
**背景**：v3.1.0 引入周期活动后，关开关 / 编辑 / 删除 / 审核 / 已开奖期保护等流程未明确，本文件统一规则。

---

## 1. 核心心智模型

楼层抽奖的运营操作分为三层独立维度，互不影响：

| 维度 | 操作 | 作用层 | 对后台运行的影响 | 对 C 端的影响 |
|---|---|---|---|---|
| **可见性** | 关开关 | C 端展示层 | 无 | 唯一闸门：决定帖子入口显隐 |
| **配置变更** | 编辑 | 活动配置层 | 提交期间停跑、通过后续跑 | 编辑期间整体下线 |
| **数据归档** | 删除 | 数据可见性层 | 不影响后台调度（已开奖记录、私聊链接仍可用）| 活动从列表/帖子消失 |

> **优先级**：`关开关` > `编辑/删除` 对 C 端入口的影响。开关「关」即使活动正常跑、未删除，C 端入口也不展示。

---

## 2. 模块：编辑 / 开关 / 删除（详细规则）

### 2.1 关开关

#### 性质
临时控制 C 端入口可见性的独立开关，**与活动后台运行完全解耦**。

#### 适用状态
| 活动状态 | 开关可操作 | 备注 |
|---|---|---|
| 待审核 | ✅ | 默认关 |
| 未开始 | ✅ | 默认开 |
| 进行中 | ✅ | 默认开 |
| 已结束 | ✅ | 默认开 |
| 已拒绝 | ✅ | 无约束（被拒活动本身不对外）|

#### 行为定义
| 操作 | 后台行为 | C 端行为 |
|---|---|---|
| 开 → 关 | **完全无影响**：到时开始、到期开奖、私聊发奖链接全部照常 | 帖子内活动入口立即隐藏 |
| 关 → 开 | 完全无影响 | 帖子内活动入口立即恢复 |

#### 关键场景
- 周期活动跑到第 4 期时关开关 → 第 4 期及之后所有周期照常自动发奖，中奖玩家通过私聊链接领奖
- 关开关「关」期间到了活动开始日 → 后台仍判定活动开始，按计划运行；C 端入口始终不显示，玩家无法参与
- 关开关「关」期间到了周期 24:00 → 正常开奖，正常发私聊链接

---

### 2.2 编辑

#### 性质
撤回当前活动 → 修改配置 → 重新审核上线。**同一个活动**，新配置覆盖**未开奖期**。

#### 适用状态
| 活动状态 | 编辑可操作 |
|---|---|
| 待审核 | ✅ |
| 未开始 | ✅ |
| 进行中 | ✅ |
| 已结束 | ❌（不展示编辑按钮）|
| 已拒绝 | ✅（按钮文案为「重新编辑」）|

#### 可编辑字段（仅 3 项）
| 可编辑 | 锁定（置灰只读）|
|---|---|
| 活动名称 | 活动类型、关联作者、活动类型、活动时间、周期总数、发奖方式、参与条件勾选、关注子项、评论关键词「匹配关键词」/「匹配类型」、按周期配置的关键词、统一关键词、投票选项、楼层抽奖规则 |
| 活动奖品 | |
| 活动说明 | |

> **锁定原因**：周期活动依赖时间/条件/关键词等强一致性配置，中途修改会破坏已发奖期与未发奖期之间的连续性。仅文案与奖品（仅影响未开奖期）允许调整。

#### 流程

```
[运营点编辑] → 进入编辑页 → [修改 3 项字段] → 提交审核
     ↓
   活动状态 = 待审核（编辑中）
   C 端整体下线暂停
   后台停止开奖（周期到点跳过不补发）
     ↓
   ┌──────────┴──────────┐
   审核通过                审核被拒
     ↓                       ↓
   新配置覆盖未开奖期       状态 = 已拒绝
   重新上线（受开关控制）   保持下线
   已开奖期保留旧配置       「重新编辑」入口可见
```

#### 编辑期间的行为

| 维度 | 行为 |
|---|---|
| C 端帖子入口 | 隐藏 |
| 私聊已发的领奖链接 | **仍可领**（不受影响）|
| 后台周期开奖 | **停跑**：到点的周期跳过，不补发、不顺延、不留占位 |
| 关开关 | 仍可手动操作（编辑通过后开关状态保留）|

#### 审核通过后

| 字段 | 生效范围 |
|---|---|
| 活动名称 | 即时生效，含所有已发出去的私聊链接（不做历史快照）|
| 活动奖品 | 仅未开奖期使用新奖品；已开奖期保留旧奖品 |
| 活动说明 | 即时生效 |

#### 审核被拒后

- 状态变为「已拒绝」
- 不自动恢复上线
- 列表页显示「重新编辑」按钮，运营修改后可再次提交
- 不提供「撤销编辑、强制上线」入口

---

### 2.3 删除

#### 性质
将活动从运营视图归档，**不影响已开奖用户的既得权益**。

#### 适用状态
| 活动状态 | 删除可操作 |
|---|---|
| 待审核 | ✅ |
| 未开始 | ✅ |
| 进行中 | ✅ |
| 已结束 | ✅ |
| 已拒绝 | ✅ |

> 任意状态都可删，前端弹窗二次确认。

#### 权限
有楼层抽奖管理权限的运营都可删除，不区分申请人。

#### 删除后影响

| 对象 | 删除后状态 |
|---|---|
| 活动列表 | 活动消失 |
| 帖子内活动入口 | 隐藏 |
| 后台调度任务 | 停跑（不再有新的开奖、不再发新链接）|
| **已开奖记录** | **一并删除**（「抽奖记录」页同步移除）|
| **私聊已发的领奖链接** | **保留可领**（链接独立于记录，中奖用户体验不受影响）|
| **草稿恢复** | 不支持（删除即不可恢复，二次弹窗强提示）|

#### 二次确认文案
```
确定删除活动「XXX」吗？
[取消] [确定删除]
```

---

## 3. 三种操作的对照速查

| 维度 | 关开关 | 编辑 | 删除 |
|---|---|---|---|
| C 端入口 | 隐藏/显示 | 编辑期间隐藏，通过后恢复 | 永久隐藏 |
| 后台开奖 | 不影响 | 停跑直到审核通过 | 停跑 |
| 已开奖记录 | 不影响 | 不影响 | **一并删除** |
| 私聊领奖链接 | 不影响 | 不影响 | 保留可领 |
| 可恢复性 | 随时切换 | 审核通过即恢复 | 不可恢复 |
| 触发审核 | 否 | 是 | 否 |

---

## 4. 列表页状态与操作按钮

| 状态 | 含义 | 操作按钮 |
|---|---|---|
| 待审核 | 新建/编辑后等待审核 | 编辑、删除 |
| 未开始 | 已通过审核，活动未到开始日 | 编辑、复制、删除 |
| 进行中 | 活动运行中 | 编辑、复制、记录、删除、（人工审核场景）奖励发放 |
| 已结束 | 活动结束日已过 | 复制、记录、删除 |
| 已拒绝 | 编辑被拒，处于下线状态 | 重新编辑、删除 |

> 「关开关」字段独立展示在首列，不随状态变化。

---

## 5. 跳过周期的处理（编辑场景）

- 编辑审核期间错过的周期 → **跳过、不补发、不顺延结束日**
- 抽奖记录**不留占位**（运营自行通过审核记录追溯）
- 总周期数不变，该期数据为空

---

## 6. 既得权益保护汇总

| 保护对象 | 不受影响的操作 |
|---|---|
| 已开奖记录 | 关开关、编辑、编辑被拒、活动结束（**删除会一并清除**） |
| 私聊领奖链接 | 关开关、编辑、编辑被拒、删除、活动结束 |
| 已开奖期的奖品 | 编辑改奖品（仅影响未开奖期）|

---

## 7. 异常场景

| 场景 | 处理 |
|---|---|
| 编辑期间活动自然结束日已过 | 编辑作废，活动归档为「已结束」；已开奖期保留 |
| 删除已被编辑提交（待审核中）的活动 | 直接删除，正在审核的编辑请求作废 |
| 关开关「关」期间到了活动开始日 | 后台仍判定活动开始，按计划运行；C 端入口始终不显示 |
| 关开关「关」期间到了周期 24:00 | 正常开奖，正常发私聊链接 |
| 已开奖记录的奖品被编辑改了 | 已开奖记录展示旧奖品；未开奖期用新奖品 |

---

## 8. 验收清单

### 关开关
1. 关开关「关」时，进行中的周期活动后台仍按时开奖并发送私聊链接
2. 关开关「关」时，C 端帖子入口隐藏，详情页不可见
3. 关开关优先级最高：「关」时无论活动处于什么状态，C 端入口都不展示，但后台活动照常运行
4. 关开关状态在编辑通过后保留，不重置

### 编辑
5. 编辑表单中：仅活动名称、活动奖品、活动说明可改，其余字段全部置灰
6. 编辑提交后，C 端整体下线；后台周期到点跳过不发奖
7. 编辑期间错过的周期不补发、不顺延结束日、记录中不留占位
8. 编辑审核通过后，新配置仅覆盖未开奖期，已开奖期保留旧奖品/旧条件
9. 编辑活动名称后，已发出去的私聊链接展示最新名称
10. 编辑审核被拒，活动状态显示「已拒绝」并保持下线，列表页出现「重新编辑」按钮
11. 已结束的活动不展示编辑按钮

### 删除
12. 任意状态下都可点击删除，弹窗二次确认
13. 删除后活动从列表消失，不可恢复
14. 删除后已开奖记录在「抽奖记录」页同步移除（不可查）
15. 删除后中奖用户的私聊领奖链接仍可正常领奖（链接独立于记录）
16. 删除待审核中的活动，正在审核的请求作废

### 通用
17. 已开奖用户的私聊领奖链接在任何运营操作（关开关/编辑/编辑被拒/**删除**/活动结束）后均可正常领奖
