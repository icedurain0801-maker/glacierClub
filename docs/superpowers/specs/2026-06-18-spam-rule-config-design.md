## 4. Tab 详细设计

### 4.1 总开关 Tab

单卡片，内容：
- 开关行：标签「内容治理功能」+ toggle + 状态文字「已开启」/「已关闭」
- 说明文案（灰色辅助文字）：「关闭后所有判定规则停止运行，已有打标数据不受影响」

Toggle 规范遵循 constraint.md：轨道 36×20，关闭态 `#d9d9d9`，开启态 `#1890ff`。

---

### 4.2 词库管理 Tab

子 Tab：`[灌水词库]` / `[恶意词库]`，两者 DOM 结构完全相同，数据独立。

**操作栏（每个子 Tab 顶部）**：
- 文本输入框（placeholder：输入词语，按 Enter 或点「添加」）+ 「添加」按钮
- 「导入」按钮（触发上传弹窗）
- 「下载导入模板」链接（下载单列 CSV，列名 `word`）

**词条表格**：

| 列 | 宽度 | 说明 |
|----|------|------|
| 词语 | flex | 词条内容 |
| 创建时间 | 160px | mock 固定时间 |
| 操作 | 80px | 「删除」红色文字按钮 |

初始 mock 数据：灌水词库预置 `good / nice / 顶 / 赞 / 666`，恶意词库预置 `垃圾 / 骗子 / 滚`。

**导入弹窗**（572px）：
- 上传区域（虚线框，支持点击选文件，接受 `.xlsx` / `.csv`）
- 解析后预览区：表格展示前 5 行词条 + 「共 N 条」提示
- 底部：「取消」+ 「确认导入」按钮
- 导入模板内容：单列 CSV，第一行 `word`，后续示例词条 3 行

---

### 4.3 规则配置 Tab

**规则列表卡片**（上方）：

| 列 | 说明 |
|----|------|
| 启用 | checkbox |
| 规则编号 | R1~R9 |
| 规则名称 | 中文简称 |
| 说明 | 一句话描述判定逻辑 |

R1~R9 名称与说明：

| 编号 | 名称 | 说明 |
|------|------|------|
| R1 | 词库命中 | 内容归一化后完全等于词库中某个词 |
| R2 | 有效字数不足 | 有效字数（去重复后）少于 4 个 |
| R3 | 无文字内容 | 无任何文字或数字字符（纯表情/符号）|
| R4 | 表情符号占比高 | 表情+符号字符占比 ≥ 70% |
| R5 | 单字符占比高 | 最高频单字符占比 ≥ 80% |
| R6 | 整条复读 | 内容为某子串重复 ≥ 3 次 |
| R7 | 纯数字 | 去除标点后全为数字 |
| R8 | 词库词堆砌 | 所有切分片段均属于词库词条 |
| R9 | 键盘乱码 | 连续键位串或无元音字母串 |

默认全部勾选（enabled）。

**阈值配置卡片**（下方）：

- 行1：「命中以下数量规则，判定为 **灌水（spam）**：≥」+ 数字输入框（默认 `2`，min=1）
- 行2：「命中以下数量规则，判定为 **嫌疑（marked）**：≥」+ 数字输入框（默认 `1`，min=1）
- 辅助说明：「低于嫌疑阈值的内容判定为正常（normal）」
- 约束：spam 阈值必须 > marked 阈值，不满足时保存时提示错误

**保存按钮**：卡片底部，`alert('保存成功')` 占位。
