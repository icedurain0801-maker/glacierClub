## 弹窗设计

### 触发方式
- 点击列表页"新增"按钮 → 打开新增弹窗（标题"新增徽章"）
- 点击行内"编辑"按钮 → 打开编辑弹窗（标题"编辑徽章"，预填当前行数据）

### 弹窗结构
- 遮罩层 `rgba(0,0,0,0.45)` 覆盖整个视口
- 弹窗居中，宽 520px，最大高度 80vh，内容区可滚动
- 顶部：标题 + 右上角 × 关闭按钮
- 顶部语言 Tab（仅展示"中文"）
- 右上角意见反馈标志（与截图5一致，装饰性）

### 表单字段（按顺序）

1. **所属版块** `*` — 标签展示（蓝色 pill，只读，显示"超能世界"）
2. **徽章名称** `*` — 下拉选择器（placeholder: 请输入徽章名称）
3. **描述** `*` — 文本输入（placeholder: 请输入徽章描述）
4. **级别** `*` — 下拉（珍贵 / 稀有 / 史诗 / 传奇 / 普通）
5. **图标** `*` — 上传区（100×100px 虚线框，+ 号，说明文字：尺寸建议64×64，png/jpg格式，内存2M以内）
6. **分类** `*` — 下拉（活跃成就 / 社交影响 / 互动传播）
7. **获得条件** `*` — 下拉（连续登录 / 累计点赞 / 累计评论 / 累计发帖 / 累计收藏）+ 数值输入框 + 单位文本（天/次，根据条件类型显示）
8. **排序** `*` — 数字输入框
9. **奖品选择** — 见下方专项设计
10. **提交** — 右下角蓝色按钮

### 奖品选择字段详细设计

```
┌─ 奖品选择 ──────────────────────────────────────────┐
│  [游戏道具 ▼]  [道具名称输入/ID ▼]  [数量输入]  [添加] [清空] │
│  （选头像框时隐藏数量输入框）                          │
│                                                      │
│  已添加奖品：                                         │
│  ┌──────────┐ ┌──────────┐                          │
│  │ 💎 灵石×10 [×] │ │ 🖼️ 深海龙头像 [×] │            │
└─────────────────────────────────────────────────────┘
```

**奖品类型下拉选项：** 游戏道具 / 头像框

**选择"游戏道具"时：**
- 显示：道具名称/ID 输入框（placeholder：请输入物品名称（ID））+ 数量输入框（placeholder：最大输入：999999...）+ 添加按钮 + 清空按钮
- 添加后：已添加奖品列表，每个奖品显示为 tag：图标 + 名称 + ×数量 + [×] 移除按钮

**选择"头像框"时：**
- 显示：头像框名称/ID 输入框 + 添加按钮 + 清空按钮（无数量输入框）
- 添加后：已添加奖品列表，每个奖品显示为 tag：图标 + 名称 + [×] 移除按钮

**约束：**
- 最多可添加5个奖品（游戏道具+头像框合计）
- 超出5个时添加按钮禁用并提示
