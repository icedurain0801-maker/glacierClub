# 充值中心新增「企微活动页」Tab 设计

日期：2026-06-09
文件：`operations/rechargeCenter/recharge-center.html`（单文件 HTML 原型）

## 需求

在 `recharge-center.html` 的网页右上角新增一个 tab 栏，包含两个 tab：

1. **充值页** —— 现有的官方充值中心（默认展示）。
2. **企微活动页** —— 复刻参考截图的《我当老祖》风格活动页，页面上有「登录账号」弹窗，按照账号登录的样式，新增一个「角色验证登录」入口。

## 范围

- 只改这一个 HTML 文件，原生 JS + CSS，无框架、无后端。
- 现有充值中心视图、全屏登录页 `#lgPage`、需求说明 drawer **均不改动逻辑**（仅按需复用）。

## 设计

### 1. Tab 栏 + 视图切换

- 在网页右上角放一个 `position:fixed` 分段控件，两个 tab：`充值页 ｜ 企微活动页`，红金配色呼应充值主题。位置：`top:24px; right:24px`，不与右下角「需求说明」悬浮按钮冲突。
- phone-shell 内的 `.rc-scroll` 拆成两个并列视图：
  - `#viewRecharge`：现有充值中心内容（banner + 登录栏 + 代金券网格），结构不变。
  - `#viewActivity`：新增企微活动页，默认 `display:none`。
- `switchView(view)`：切换两个 view 的显隐，并更新 tab 的 active 态。默认 `recharge`。
- 全屏登录页 `#lgPage` 与需求说明 drawer 保持在原层级，两个视图共用。

### 2. 企微活动页内容（`#viewActivity`，完整还原截图）

自顶向下：

1. **游戏背景插画区**（CSS / emoji 拼近似氛围，非真实游戏美术）：
   - 水墨绿渐变底，营造国风游戏氛围。
   - 顶部左侧「我当老祖」标题徽记（文字 + 描边样式）。
   - 一个角色立绘占位（emoji，如 🧙 / 🧑‍🎤 配 CSS 装饰）。
   - 右上角「登录」描边按钮（点击亦可打开登录弹窗）。
2. **「登录账号」弹窗**（叠在背景上，带半透明遮罩，默认展示）：
   - 仿截图卷轴弹窗样式：米绿底、红色描边、标题「登录账号」带左右菱形装饰、右上关闭 ✕。
   - 说明文案：「请老祖根据自身实际情况，选择登录方式」。
   - 两个并列入口按钮：
     - 「账号登录」（红色实心，复刻截图）→ `openLogin('account')`
     - 「角色验证登录」（新增，描边/次级样式）→ `openLogin('role')`
   - 关闭：点 ✕ 关闭弹窗（仅隐藏弹窗，停留在活动页）；右上角「登录」按钮可重新唤起。
3. **底部「每月签到礼」**：
   - 标题「每月签到礼」。
   - 三个奖励卡（emoji 占位图 + 文案）：仙玉×210 / 利爪当归种子×17 / 大灵雨符×51。
   - 红色「前往签到」按钮（`alert` 占位）。

### 3. 交互复用

- 现有 `openLogin()` 扩展为 `openLogin(tab)`：打开 `#lgPage` 后，若传入 tab 则调用已有 `lgSwitchTab(tab)` 切到对应表单（`account` / `role` / `phone`）。无参数时保持默认（手机登录）。
- `#lgPage` 内已有三个 tab（手机登录 / 账号登录 / 角色验证登录）与对应表单、`lgSendCode`、`lgSubmit`，全部复用，不新增表单。
- 登录成功（`lgSubmit`）后：维持现有充值中心角色回显逻辑；活动页弹窗在再次打开活动页时可手动关闭，无需特殊联动。

### 4. 不改动项

- 需求说明 drawer 已含「角色验证码登录」完整 PRD，保持不变。
- 充值中心代金券网格、购买逻辑 `buy()` 不变。

## 验证

- 浏览器打开页面，默认显示充值页，右上角 tab 可切到企微活动页。
- 企微活动页背景 + 弹窗 + 签到礼三段齐全，近似截图。
- 弹窗「账号登录」→ 全屏登录页落在「账号登录」tab；「角色验证登录」→ 落在「角色验证登录」tab。
- 弹窗 ✕ 可关闭，右上角「登录」按钮可重新唤起。
- 切回充值页，原功能正常。
