> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新建 `bigPlayer/client-new/news_src.html`，1:1 复刻截图中的资讯页，风格与 `home_src.html` 完全一致。

**Architecture:** 纯静态 HTML 文件，复用 `home_src.html` 的 Tailwind CDN 配置（色彩 token、字体、图标库）。页面分为固定顶部（Tab 栏）、可滚动内容区（排序行 + 3 张大图卡片）、固定底部导航栏三层。

**Tech Stack:** Tailwind CSS CDN、Material Symbols Outlined、Google Fonts (Inter/Manrope)、纯静态 HTML
