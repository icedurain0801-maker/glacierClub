# v3.0.9 变更日志

**版本：** v3.0.9  
**日期：** 2026-04-07  
**撰写：** 刘福毅

---

## C 端

**徽章墙**
- 有奖励的徽章图标左上角新增礼包 icon，标识该徽章达成后可获得道具/头像框奖励

**徽章详情**
- 「佩戴徽章」按钮上方新增「达成可获得」奖励展示区，最多展示 5 个（游戏道具 + 头像框）

**徽章获得通知**（新增页面）
- 用户达成徽章条件后弹出通知弹窗，展示徽章图片、名称、稀有度、获得条件及奖励列表

**角色信息确认**（新增页面）
- 奖励含游戏道具（数量 ≥ 1）时，点击「查看详情」跳转本页，用户选择接收奖励的角色（来源为冰川通行证绑定角色，默认选 ID 最小的角色）；道具数量为 0 时直接发放，不跳转

---

## 管理后台

**徽章管理**（新增页面）
- 徽章列表：支持按版块/状态/名称/分类筛选，表格展示级别、图标、描述、条件、领取人数、状态等
- 新增/编辑弹窗：支持配置徽章基本信息、获得条件、奖品（游戏道具+数量 / 头像框，最多 5 个）

**侧边导航**
- 后台新增「徽章管理」「徽章分类管理」导航入口
- 所有导航目录默认展开，无需手动点击展开
