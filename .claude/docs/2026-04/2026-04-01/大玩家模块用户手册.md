## 2. 导航到大玩家模块

**操作步骤：**

1. 在左侧导航栏点击「**运营中心**」，展开运营中心子菜单

   ![运营中心展开](../../../../.temp/screenshots/02_yunying_expanded.png)

2. 点击「**大玩家**」，展开大玩家所有子模块

   ![大玩家菜单](../../../../.temp/screenshots/03_dawanjia_expanded.png)

大玩家模块包含以下六个功能组：
- 内容管理（帖子管理、评论管理、回收站、协管员申请管理）
- 社区功能（徽章管理、装扮管理、创作中心管理、轮播图管理、攻略组管理）
- 用户管理（用户标签设置、用户管理、头像管理、昵称管理、用户标签管理）
- 日志管理（大模型参数管理、AI机器人会话记录、举报日志）
- 数据管理（用户数据分析）
- 版块管理（版块列表）

## 3. 内容管理

内容管理负责对社区内帖子、评论等内容进行审核与管理。点击「**内容管理**」展开子菜单。

### 3.1 帖子管理

**路径：** 运营中心 → 大玩家 → 内容管理 → 帖子管理

**功能说明：** 查询和管理社区内所有帖子，支持按所属版块、外显 ID 等条件筛选，可对帖子执行加精、删除等操作。

![帖子管理](../../../../.temp/screenshots/05_post_mgmt.png)

**主要操作：**

| 操作 | 说明 |
|------|------|
| 搜索筛选 | 按版块、标签 ID、外显 ID、图文类型查询 |
| 加精 | 将优质帖子设置为精华内容 |
| 删除 | 删除违规或不合规帖子 |
| 查看详情 | 点击帖子 ID 查看完整内容 |

---

### 3.2 评论管理

**路径：** 运营中心 → 大玩家 → 内容管理 → 评论管理

**功能说明：** 管理所有用户评论，支持按版块、图文类型筛选，可批量或单条删除违规评论。

![评论管理](../../../../.temp/screenshots/06_comment_mgmt.png)

**主要字段说明：**

| 字段 | 说明 |
|------|------|
| 评论 ID | 评论唯一标识 |
| 评论内容 | 用户发布的评论文本 |
| 所属帖子 | 评论所在帖子 |
| 状态 | 正常 / 已删除 |
| 举报次数 | 被用户举报的累计次数 |
| 创建时间 | 评论发布时间 |

---

### 3.3 回收站

**路径：** 运营中心 → 大玩家 → 内容管理 → 回收站

**功能说明：** 存放已被删除的帖子和评论，支持按版块、删除人、删除时间范围筛选，可查看删除记录详情。

![回收站](../../../../.temp/screenshots/07_recycle.png)

**主要字段说明：**

| 字段 | 说明 |
|------|------|
| 帖子 ID | 被删除内容的唯一标识 |
| 帖子标题 | 内容标题 |
| 删除类型 | 帖子 / 评论 |
| 删除来源 | 举报删除 / 后台删除 / 自删 |
| 发帖人 ID | 原作者标识 |
| 删除人 ID | 执行删除操作的账号 |
| 删除时间 | 操作时间 |

---

### 3.4 协管员申请管理

**路径：** 运营中心 → 大玩家 → 内容管理 → 协管员申请管理

**功能说明：** 管理用户提交的版块协管员申请，包含「帖栏列表」和「申请列表」两个标签页，支持按版块筛选并对申请进行审批操作。

![协管员申请管理](../../../../.temp/screenshots/08_moderator_apply.png)

**审批操作：**
- **批量审核**：勾选多条申请后统一处理
- 单条操作：通过 / 拒绝

**主要字段说明：**

| 字段 | 说明 |
|------|------|
| 申请 ID | 申请记录唯一标识 |
| 申请备注 | 用户填写的申请理由 |
| 所属类型 | 帖子 / 评论 |
| 申请操作 | 加精 / 删评等申请类型 |
| 帖子/动态/评论 ID | 对应内容 ID |
| 帖子内容 | 申请内容摘要 |
| 状态 | 待审核 / 已通过 / 已拒绝 |
| 所属版块 | 内容归属版块 |
