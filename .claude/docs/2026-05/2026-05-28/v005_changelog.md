# v005 Changelog · 2026-05-28

## admin/analytics/UserDataAnalysis · 新增「社区类型」筛选

筛选栏「所属版块」之后增加「社区类型」单选下拉：不限 / 网页端 / 小程序端 / APP端，默认「不限」。

- 选择具体端类型 → 累计总数与按天表格按所选端类型统计；因历史数据未按端类型区分，所有指标暂为 0，并在筛选栏下方显示黄色提示条。
- 选择「不限」→ 提示条消失，恢复全部历史数据。
- 提示文案 + 规则同步写入右侧需求说明面板（v3.1.2）。
- sidebar-data.js 入口版本号同步升至 v3.1.2。
