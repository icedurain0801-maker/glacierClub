## 二、本次变更：关开关 / 编辑 / 删除 流程规则模块

### 1. 核心心智模型

三大操作互相独立、作用域不同：

| 操作 | 性质 | 后台运行 | C 端展示 |
|---|---|---|---|
| **关开关** | 临时藏入口 | 完全无影响（到时开始、到期开奖、私聊发奖照常） | 帖子内入口隐藏 / 恢复 |
| **编辑** | 撤回审核 + 配置变更 | 提交期间停跑，审核通过后续跑 | 编辑期间整体下线 |
| **删除** | 数据归档 | 停跑（已开奖记录、私聊链接仍可用） | 列表 / 帖子消失 |

**优先级**：关开关 > 编辑 / 删除。开关「关」即使活动正常跑、未删除，C 端入口也不展示。

### 2. 关开关 — 异常场景

| 活动状态 | 关 → | 开 → | 说明 |
|---|---|---|---|
| 待审核 | 入口隐藏 | 入口恢复 | 关开关与审核状态独立，互不影响 |
| 未开始 | 入口隐藏；后台仍按原计划到点开始 | 入口恢复 | 关开关期间到了活动开始日 → 后台仍判定活动开始，按计划运行；C 端入口始终不显示 |
| 进行中（单次 / 周期）| 入口隐藏；后台照常跑、照常开奖、私聊照常发链接 | 入口恢复 | 关开关期间到了周期 24:00 → 正常开奖，正常发私聊链接 |
| 已结束 | 入口隐藏（仅影响入口可见性） | 入口恢复 | — |
| 已拒绝 | 入口隐藏（被拒活动本身不对外，意义有限） | 入口恢复 | 不做特殊限制 |

> 关键示例：周期活动跑到第 4 期时关开关 → 第 4 期及之后所有周期照常自动发奖，中奖玩家通过私聊链接领奖。

### 3. 编辑 — 异常场景

#### 3.1 可编辑字段（仅 3 项）

| 可编辑 | 锁定（置灰只读） |
|---|---|
| 活动名称、活动奖品、活动说明 | 活动类型、关联作者、活动时间、周期总数、发奖方式、参与条件勾选、关注子项、评论关键词「匹配关键词」/「匹配类型」、按周期配置的关键词、统一关键词、投票选项、楼层抽奖规则 |

**锁定原因**：周期活动依赖时间/条件/关键词等强一致性配置，中途修改会破坏已发奖期与未发奖期之间的连续性。仅文案与奖品（仅影响未开奖期）允许调整。

#### 3.2 各状态编辑流程

| 活动状态 | 编辑提交后 | 期间到点的周期 | 审核通过 | 审核被拒 |
|---|---|---|---|---|
| 未开始 | C 端下线暂停 | （未到期） | 新配置覆盖，按原排期上线 | 状态变为「已拒绝」，保持下线 |
| 进行中 · 已跑 N 期 | C 端下线暂停；后台停跑 | **跳过不补发**，不顺延结束日，记录不留占位 | 新配置覆盖未开奖期；已开奖期保留旧配置 / 旧奖品 | 状态变为「已拒绝」，保持下线 |
| 已结束 | 不展示编辑按钮 | — | — | — |
| 已拒绝 | 显示「重新编辑」按钮，可再次提交 | — | 状态恢复 | 继续保持「已拒绝」 |

#### 3.3 编辑期间 vs 审核通过后

| 维度 | 编辑期间 | 审核通过后 |
|---|---|---|
| C 端帖子入口 | 隐藏 | 受开关控制 |
| 私聊已发的领奖链接 | 仍可领（不受影响） | 仍可领 |
| 后台周期开奖 | 停跑：到点的周期跳过 | 未开奖期按新配置开奖 |
| 活动名称 | — | 即时生效，含所有已发出去的私聊链接 |
| 活动奖品 | — | 仅未开奖期使用新奖品；已开奖期保留旧奖品 |
| 活动说明 | — | 即时生效 |

#### 3.4 已拒绝状态的恢复路径

- 列表页显示「重新编辑」按钮
- 点击 → 进入编辑页修改 → 重新提交审核
- 审核通过 → 状态回到「进行中 / 未开始 / 已结束」（按活动时间判断）
- 不提供「跳过编辑、强制上线」入口

### 4. 删除 — 异常场景

| 维度 | 规则 |
|---|---|
| 适用状态 | 任意状态都可删（待审核 / 未开始 / 进行中 / 已结束 / 已拒绝） |
| 权限 | 有楼层抽奖管理权限的运营都可删，不区分申请人 |
| 二次确认 | 弹窗：「确定删除活动「XXX」吗？」+ 取消 / 确定删除 |
| 活动列表 | 删除后从列表消失 |
| 帖子内活动入口 | 隐藏 |
| 后台调度任务 | 停跑（不再有新的开奖、不再发新链接） |
| 已开奖记录 | 保留可查（「抽奖记录」页） |
| 私聊已发的领奖链接 | 保留可领，中奖用户体验不受影响 |
| 可恢复性 | 不可恢复 |

### 5. 三操作影响对照速查

| 维度 | 关开关 | 编辑 | 删除 |
|---|---|---|---|
| C 端入口 | 隐藏 / 显示 | 编辑期间隐藏，通过后恢复 | 永久隐藏 |
| 后台开奖 | 不影响 | 停跑直到审核通过 | 停跑 |
| 已开奖记录 | 不影响 | 不影响 | 保留可查 |
| 私聊领奖链接 | 不影响 | 不影响 | 保留可领 |
| 可恢复性 | 随时切换 | 审核通过即恢复 | 不可恢复 |
| 触发审核 | 否 | 是 | 否 |

### 6. 既得权益保护

- **已开奖记录**：永久保留，关开关 / 编辑 / 被拒 / 删除 / 结束都不影响
- **私聊领奖链接**：始终可领，任何运营操作不影响
- **已开奖期奖品**：编辑改奖品仅影响未开奖期，已开奖期按当时奖品发放

### 7. 其他异常场景

| 场景 | 处理 |
|---|---|
| 编辑期间活动自然结束日已过 | 编辑作废，活动归档为「已结束」；已开奖期保留 |
| 删除已被编辑提交（待审核中）的活动 | 直接删除，正在审核的编辑请求作废 |
| 已开奖记录的奖品被编辑改了 | 已开奖记录展示旧奖品；未开奖期用新奖品 |

## 三、列表页状态与操作按钮

| 状态 | 含义 | 操作按钮 |
|---|---|---|
| 待审核 | 新建 / 编辑后等待审核 | 编辑、删除 |
| 未开始 | 已通过审核，活动未到开始日 | 编辑、复制、删除 |
| 进行中（人工审核） | 活动运行中 | 奖励发放、编辑、复制、记录、删除 |
| 进行中（自动发奖） | 活动运行中 | 编辑、复制、记录、删除 |
| 已结束 | 活动结束日已过 | 复制、记录、删除 |
| 已拒绝 | 编辑被拒，处于下线状态 | 重新编辑、删除 |

> 「关开关」字段独立展示在首列，不随状态变化，任意状态可操作。

## 五、验收清单

### 关开关
1. 关开关「关」时，进行中的周期活动后台仍按时开奖并发送私聊链接
2. 关开关「关」时，C 端帖子入口隐藏，详情页不可见
3. 关开关优先级最高：「关」时无论活动处于什么状态，C 端入口都不展示
4. 关开关状态在编辑通过后保留，不重置

### 编辑
5. 编辑表单中：仅活动名称、活动奖品、活动说明可改，其余字段全部置灰
6. 编辑提交后，C 端整体下线；后台周期到点跳过不发奖
7. 编辑期间错过的周期不补发、不顺延结束日、记录中不留占位
8. 编辑审核通过后，新配置仅覆盖未开奖期，已开奖期保留旧奖品 / 旧条件
9. 编辑活动名称后，已发出去的私聊链接展示最新名称
10. 编辑审核被拒，活动状态显示「已拒绝」并保持下线，列表页出现「重新编辑」按钮
11. 已结束的活动不展示编辑按钮

### 删除
12. 任意状态下都可点击删除，弹窗二次确认
13. 删除后活动从列表消失，不可恢复
14. 删除后已开奖记录仍可在「抽奖记录」页查询
15. 删除后中奖用户的私聊领奖链接仍可正常领奖
16. 删除待审核中的活动，正在审核的请求作废

### 通用
17. 已开奖用户的私聊领奖链接在任何运营操作（关开关 / 编辑 / 编辑被拒 / 删除 / 活动结束）后均可正常领奖
