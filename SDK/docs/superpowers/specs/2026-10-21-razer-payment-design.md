# Razer 支付配置设计

Status: approved-for-review  
Updated: 2026-10-21

## 目标

在 SDK 管理后台的支付配置管理原型中增加“Razer支付”方案类型，支持按游戏版本配置 Razer 支付参数。

## 范围

1. 在方案类型选择器中新增“Razer支付”，固定排序为“Terminal3支付”之后、“Xsolla支付”之前。
2. Razer 支付展示必填的游戏版本下拉，选项和默认行为复用现有新增支付渠道。
3. Razer 支付仅配置下列必填渠道参数：
   - 应用编码（`applicationCode`）：文本输入。
   - 密钥（`secretKey`）：密码输入。
4. 不展示、不校验 `gameId` 和 `sandbox`。启用状态复用现有开关。
5. 同步支付列表演示数据、筛选选项、需求说明和 2026-10-21 变更文档。

## 实现边界

- 复用现有配置驱动的类型、字段、游戏版本、草稿隔离及必填校验机制，不创建 Razer 专属表单分支。
- 表单布局保持“方案类型 → 游戏版本 → 方案名称 → 分隔线 → 渠道字段 → 启用状态”。
- 静态原型只做浏览器端校验；不调用接口，不持久化、不记录渠道密钥。

## 验收

1. 下拉搜索与键盘选择可选中 Razer 支付，位置正确。
2. Razer 表单存在游戏版本、应用编码和密钥，且不存在 `gameId`、`sandbox`。
3. 未填写任一必填字段提交时显示现有错误提示；填写后仅提示静态原型校验通过。
4. 列表可按 Razer 支付筛选并展示一条 Razer 演示配置。
5. 需求抽屉与实现字段一致。
