# SDK 登录页面还原

日期：2026-08-03

## 变更内容

根据 SDK 登录截图，还原正式登录原型的三个状态：

- 登录方式选择页：账号、手机、第三方登录入口。
- 账密登录页：账号输入、密码输入、登录按钮、忘记密码和注册入口。
- 手机号登录页：手机号输入、登录按钮和获取验证码入口。

## 视觉规则

- 背景采用更深邃的游戏氛围渐变（蓝绿→深蓝→紫→近黑）。
- 统一白色圆角弹窗，弹窗边缘透出蓝色微光。
- 输入框改为浅蓝灰圆角卡片样式（非下划线）。
- 登录按钮改为渐变胶囊样式，带蓝色投影。
- 第三方图标增加品牌色微光。
- 统一蓝白文字配色。

## 交互规则

- 首页点击账号或手机进入对应登录页。
- 登录页可通过返回按钮回到登录方式选择页。
- 账密和手机号登录分别累计失败次数，连续失败 3 次后显示更小的滑块验证子弹窗。
- 第三方登录入口不触发滑块验证。
- 当前原型中的登录、验证码和第三方请求仍为前端演示交互，不连接真实服务。
