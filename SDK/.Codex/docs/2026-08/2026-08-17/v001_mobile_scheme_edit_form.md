# 移动端 SDK 方案编辑页改造

日期：2026-08-17

## 变更内容

将 `admin/schemeManagement/schemeList.html` 中移动端 SDK 方案点击“编辑”后的页面，改造成接近已登录后台方案编辑页的完整配置表单；列表页、查看页、编辑页路由及非移动端编辑模板保持不变。

## 页面结构

移动端编辑模式按配置领域拆分为独立卡片：

1. 基本信息
2. 合规信息
3. 自定义设置
4. 未成年人 / 人脸识别
5. 推荐设置
6. 日活、登录与账号配置
7. 支付
8. 悬浮球
9. 广告回传
10. 智能客服

编辑页保留方案头部、标签栏和底部固定保存栏，并使用双列字段布局；窄屏下自动切换为单列布局。

## 字段与交互

- 文本、URL、数字、下拉框、单选、复选和开关控件均按字段加入演示表单。
- `data-field` 用于统一收集表单值；复选项按字段保存数组，单选项保存当前值，开关保存布尔状态。
- 保存后按方案名称缓存移动端草稿，重新进入同一方案编辑页时自动回显。
- 保存会更新页面标题和保存提示，并保留现有原型中的“方案已保存”提示；取消只返回列表，不写入当前修改。
- 移动端编辑模式隐藏通用编辑卡片，非移动端方案仍使用原有通用编辑模板。

## 验证

- 通过内联 JavaScript `node --check` 语法检查。
- 通过 `git diff --check`。
- 使用本地 HTTP 服务器打开列表，点击首个移动端方案的编辑入口，确认移动端编辑模式、完整卡片字段、表单双列结构、固定操作栏和未成年人 / 人脸识别配置可见。
- 浏览器验证过程中未提交真实后台数据；当前页面保存为本地原型草稿行为。
