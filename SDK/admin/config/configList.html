需求说明 · 配置审核

本页配置列表本次改动汇总

需求背景

配置项编辑提交后、审核通过前，存在一段审批真空期。此前系统会直接读取修改中的方案，导致正式线上环境的 SDK 方案丢失/裸奔，玩家侧读不到有效方案。

本次采用按方案类型区分的兜底策略：只有审核通过并处于生效中的方案才进入读取链路；移动端 SDK 在渠道没有配置、方案未生效或方案不可用时，读取系统默认方案；模拟器、专属客服、小游戏等其他类型方案在上述情况下传空，并提示方案未配置。

方案读取兜底逻辑

#方案归属配置当前状态实际读取方案逻辑说明与异常处理
1渠道 / 移动端 SDK无配置记录首次接入 / 未创建方案系统默认方案移动端 SDK 没有配置时读取系统默认方案，保证基础 SDK 能力可用。
2渠道 / 其他方案无配置记录模拟器 / 客服 / 小游戏等空 + 方案未配置其他类型方案没有配置时传空，并提示「方案未配置」。

4配置方案未生效 / 不可用移动端 SDK系统默认方案移动端 SDK 方案处于编辑、审核中、待审核、审核不通过、已过期或已删除等状态时，读取系统默认方案。

8新方案审核通过正式生效新方案（正式生效数据）审核通过后新方案正式生效，进入对应方案类型的读取链路。

主列表状态

  • 主列表状态统一为四种：生效中（绿色）、已过期（灰色）、待审核（琥珀色）、审核不通过（红色）。
  • 生效中：配置方案已审核通过并正式生效，生效时间(止)未过期，正式读取该生效方案。
  • 已过期：配置方案的生效时间(止)已超过当前时间，或被新方案替代后自动过期；已过期方案不再读取：移动端 SDK 读取系统默认方案，其他类型方案传空并提示「方案未配置」。已过期配置无待处理申请时，操作列不显示审核入口。
  • 待审核：仅新建配置方案提交后出现此状态，表示该配置首次创建、等待审核通过后生效；审核通过前按方案类型兜底。
  • 审核不通过：仅新建配置方案被审核拒绝后出现此状态。该行保留「编辑 / 删除」，隐藏「审核」入口；正式读取时不使用被拒绝方案，移动端 SDK 读取系统默认方案，其他类型方案传空并提示「方案未配置」。
  • 编辑已有配置不会改变行状态（生效中/已过期不变），编辑申请在审核弹窗内独立流转。

新建配置方案

  • 点击列表顶部「新增」按钮，填写配置方案后提交，列表新增一行，状态为「待审核」。
  • 新建配置的审批人列显示为「— / 未审批」；审核通过前方案未生效：移动端 SDK 读取系统默认方案，其他类型方案传空并提示「方案未配置」。
  • 待审核状态的行：状态标签为琥珀色，删除按钮置灰（muted）——删除操作在审核通过前不生效。
  • 审核通过后该行状态变为「生效中」，审批人更新为审核操作人，删除按钮恢复为可操作（danger）。审核不通过后状态变为「审核不通过」，隐藏审核入口，删除按钮恢复为可操作。
  • 已有生效中方案的编辑申请，审核通过或审核不通过后均隐藏审核入口；审核不通过时主列表状态和数据保持不变。

审核弹窗 · 步骤条+单步聚焦

  • 审核弹窗采用步骤条 + 单步聚焦布局：顶部4步步骤条（编辑申请 → 内测中 → 审核中 → 已生效/不通过），中间聚焦当前步骤，底部为当前步骤的操作按钮。
  • 每个配置同一时间只有1条最新申请在审核流程中，取最新申请渲染。
  • 申请类型分为修改（编辑已有配置，显示修改前/修改后对比）和新建（新建配置方案，显示单列数据）。

两步审核流程

编辑/新建申请→ 内测中→ 审核中→ 审核通过 · 写入主列表/ 审核不通过 · 主列表不变
  • 状态统一为：内测中 / 审核中 / 审核通过 / 审核不通过；只有「审核中」可以点击「审核通过 / 审核不通过」，「内测中」只能点击「内测通过」，已完成状态仅可点击「关闭」。
  • 内测通过、审核通过/不通过均通过居中确认弹框二次确认（替代浏览器原生 confirm）。
  • 审核通过后：新建配置行状态从「待审核」变为「生效中」，新方案进入读取链路；编辑配置审核通过后申请数据生效并进入读取链路。
  • 审核不通过后：新建配置行状态改为「审核不通过」，隐藏审核入口并允许删除；编辑配置的主列表状态和数据均不变。
  • 操作完成后弹出顶部 toast 提示（"审核已通过" / "审核不通过"），弹窗关闭。

主列表数据

  • 删除「原数据」列，「修改后数据」改名为 生效中数据。
  • 审核通过后：编辑配置 → 申请数据覆盖主列表「生效中数据」，状态保持生效中；新建配置 → 行状态从「待审核」变为「生效中」，申请数据即为生效中数据。
  • 审核不通过：编辑配置只标记申请、主列表数据完全不变；新建配置行状态改为「审核不通过」，隐藏审核入口并允许删除；任何审核不通过方案均不进入读取链路，移动端 SDK 读取系统默认方案，其他类型方案传空并提示「方案未配置」。
  • 方案被删除后不再读取已删除方案，移动端 SDK 读取系统默认方案，其他类型方案传空并提示「方案未配置」。
  • 待审核状态的行：删除按钮置灰（muted），不可直接删除——删除操作在审核通过前不生效。
