## 2. 字体系统

### 基准字体
- 字体族：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`
- 行高：`1.55`

### 字号规范

| 级别 | 字号 | 字重 | 用途 | 示例 |
|------|------|------|------|------|
| H0 | 24px | 800 | 大标题（hero标题） | 页面主标题、通知标题 |
| H1 | 16px | 700 | 页面标题/顶栏标题 | 顶栏页面标题 |
| H2 | 15px | 700 | 卡片标题/面板标题 | 表格标题、面板标题 |
| H3 | 14px | 700 | 小标题 | 表单标题、栏标题 |
| H4 | 13.5px | 600 | 辅助标题 | 表格列头、说明文字 |
| Body | 14px | 400 | 正文文本 | 页面正文、列表内容 |
| Body-S | 13px | 400 | 小正文 | 表格内容、小卡片 |
| Body-XS | 12.5px | 400 | 更小正文 | 描述文字、辅助信息 |
| Body-XXS | 12px | 400 | 最小正文 | 标签、时间戳 |
| Label | 11px | 700 | 标签/徽章 | 类型标签、状态徽章 |
| Label-S | 10px | 700 | 小标签 | 小徽章、角标 |

### 字体颜色与大小对应

#### H0（24px, 800）
- 颜色：`var(--ink)` (#0b1220)
- 字母间距：`-0.02em`
- 行高：`1.25`
- 用途：hero 区域大标题

#### H1（16px, 700）
- 颜色：`var(--ink)` (#0b1220)
- 字母间距：`-0.01em`
- 用途：页面顶栏标题、通知标题

#### H2（15px, 700）
- 颜色：`var(--ink)` (#0b1220)
- 字母间距：`-0.01em`
- 用途：卡片/面板标题

#### H3（14px, 700）
- 颜色：`var(--ink)` (#0b1220)
- 用途：小标题、表单标题

#### H4（13.5px, 600）
- 颜色：`var(--ink-3)` (#475569)
- 用途：hero 小标题、表格行业标题

#### Body（14px, 400）
- 颜色：`var(--ink-2)` (#1f2937)
- 用途：主要正文

#### Body-S（13px, 400）
- 颜色：`var(--ink-2)` (#1f2937)
- 用途：表格内容、小卡片文字

#### Body-XS（12.5px, 400）
- 颜色：`var(--ink-3)` (#475569)
- 用途：描述文字、辅助说明

#### Body-XXS（12px, 400）
- 颜色：`var(--ink-4)` (#94a3b8)
- 用途：时间戳、灰色说明

#### Label（11px, 700）
- 颜色：`var(--ink-4)` (#94a3b8) 或功能色
- 字母间距：`0.05em` / `0.16em`（大写）
- 用途：表格列头、类型标签

## 3. 组件规范

### 页面布局
- 页面顶栏高度：`48px`
- 侧边栏宽度：`232px`
- 主区域顶栏高度：`60px`
- 内容区内边距：`32px 36px 36px`（竖 横 底）
- 模块间距：`24px`

### 卡片/面板
- 背景：`white`
- 边框：`1px solid var(--border)`
- 圆角：`14px`
- 内边距：`24px-32px`（根据内容）
- 阴影：`var(--shadow-sm)` (0 1px 2px rgba(15,23,42,.04))

### 按钮
- 主按钮：
  - 背景：`linear-gradient(135deg, #1e3a8a 0%, #1e40af 50%, #2563eb 100%)`
  - 文字：`white`
  - 圆角：`14px`
  - 内边距：`32px 32px 28px`
  - 字号：根据按钮位置决定

## 4. 页面结构

### 标准页面组成（参考 sdkSchemeManagement.html）

```
┌────────────────────────────────────────────┐
│  平台顶部导航（高 48px）                      │
├────────────────────────────────────────────┤
│ 侧  │ 内容区顶栏（高 60px）                   │
│ 边  ├────────────────────────────────────────┤
│ 栏  │                                        │
│ 232 │  Hero 卡片区                           │
│ px  │                                        │
│     │  操作卡片区                            │
│     │                                        │
│     │  主内容区（表格/面板）                  │
│     │                                        │
│     │  右侧栏（提示/状态）                    │
└────────────────────────────────────────────┘
```

### Hero 区域文字规范

- **Eyebrow**（小标签）：11px, 700, `var(--brand)`, 大写, 字母间距 0.16em
- **标题**：24px, 800, `var(--ink)`
- **副标题**：13.5px, `var(--ink-3)`, 行高 1.6

### 表格规范

- **表头**：11px, 700, `var(--ink-4)`, 大写, 字母间距 0.05em, 背景 `var(--bg-2)`
- **表格行**：13px, 400, `var(--ink-2)`
- **行业标签**：11px, 600, 圆角 5px, 内边距 3px 9px

## 5. 重要约定

1. **所有时间戳**应使用 12px, 400, `var(--ink-4)`
2. **所有链接和操作按钮**应使用 `var(--brand)` 颜色，12.5px, 600
3. **所有说明文字**应使用 `var(--ink-4)` 颜色，12px 或 12.5px
4. **所有标题**禁止使用 `var(--ink-2)`，最低应为 `var(--ink-3)`
5. **禁止使用其他颜色系统**，所有颜色必须来自上述色板
6. **页面内容最大宽度**建议不超过 1600px（含侧边栏）

## 6. 检查清单

新增页面完成时检查：

- [ ] 页面标题（顶栏）使用 16px, 700 字
- [ ] 卡片标题使用 15px, 700 字
- [ ] 所有标题颜色为 `var(--ink)` 或 `var(--ink-2)`
- [ ] 正文文字使用 14px 或 13px, 400 字
- [ ] 说明文字使用 12.5px 或 12px, `var(--ink-4)`
- [ ] 所有颜色来自已定义的色板
- [ ] 卡片使用 `14px` 圆角
- [ ] 内容区顶栏高度 60px
- [ ] 内容区内边距 `32px 36px 36px`
- [ ] 模块间距 `24px`
- [ ] 使用通用 sidebar.js 注入侧边栏
