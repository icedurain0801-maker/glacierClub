区域 / 字段说明
类型分组 Tab三大类型，Tab 右上角数字为该分组下可选 SDK 数量：
① 移动端（2）② 小游戏（9）③ PC 端（2）
移动端移动端 SDK、iOS 马甲包 SDK
小游戏微信小游戏、抖音小游戏、B 站小游戏、支付宝、微信小程序、华为快游戏、小米快游戏、VIVO 快游戏、OPPO 快游戏
PC 端Windows SDK、H5 SDK
SDK 类型单选必填。切换分组 Tab 后默认选中该组第一项；默认整体选中「移动端 → 移动端 SDK」。类型创建后不可修改
创建方式二选一，默认「全新创建」：
· 全新创建：所有参数留空，从零配置
· 快速创建：复制一个已有方案的参数作为初始值，再进入编辑微调
参考方案搜索框仅「快速创建」时展开。支持按方案名称模糊搜索，下拉选择一个已有方案作为参数来源；不选则无法提交
底部操作「取消」关闭弹窗；「创建并进入编辑」按所选类型 + 创建方式生成方案并跳转编辑页
方案总览列表新增
展示最近修改的方案，按「最后操作时间」倒序，默认 7 条，点「更多」跳转完整方案管理页。
字段说明
方案 ID系统生成的唯一标识（ObjectID 格式，如 63b3979ff462…），不可编辑，用于定位与排障
方案名称用户自定义名称。名称右侧合规状态图标：绿色「✓」=合规；橙色「!」=存在风险项需关注
类型SDK 方案类型，取值：移动端 SDK / H5 SDK / Windows SDK / 微信小游戏 / 抖音小游戏 / 模拟器，不同类型用不同色标
是否已关联渠道「是」=已绑定至少一个渠道包 PID（已生效）；「否」=方案存在但未挂载（灰色显示）
最后操作时间最近一次编辑/创建时间，按下方相对时间规则展示
操作人最后一次操作该方案的账号姓名
操作「查看」跳转方案详情（只读）；「编辑」进入该方案编辑页
相对时间显示规则（最后操作时间 / 操作动态时间通用，精确到天）
今天（同一自然日）今天
昨天昨天
前天 ~ 6 天前N 天前（前天显示「2 天前」）
7 ~ 29 天一周前 / 2 周前 / 3 周前（按整周向下取整）
30 ~ 364 天一个月前 / N 个月前（按整月向下取整）
≥ 365 天一年前 / N 年前（按整年向下取整）
最近操作动态新增
右侧时间轴，展示团队成员最近操作，倒序排列，点「全部记录」跳转操作日志。
字段说明
状态圆点绿色=当日操作；灰色=历史操作。最后一条不显示连接竖线
操作人执行操作的账号姓名，加粗显示
操作内容操作类型 + 对象名称，如「编辑方案【xxx】」「新增地址包【xxx】」
操作时间采用上方「相对时间显示规则」，精确到天
