未成年人合规设置新增
本版本调整未成年人合规配置：适龄提示新增 18+ 选项；适龄按钮展示时机、适龄提示详情链接、适龄按钮百分比、协议按钮、注销按钮及按钮位置字段继续保留；隐藏“未成年及游客时长限制”字段。
项说明
新建方案默认值新建方案的适龄提示默认选择「18+」
历史方案兼容历史方案沿用原有适龄提示值，不自动修改、不批量迁移
字段展示仅隐藏「未成年及游客时长限制」，其他未成年人合规配置继续展示并可编辑
配置规则与交互规则
本次调整仅作用于移动端 SDK 方案编辑页，不影响方案列表、查看页、非移动端 SDK 编辑页及既有历史数据。
场景处理规则
进入移动端方案编辑按当前方案已保存的 agePrompt 值回显；历史方案不得被默认值覆盖
新建移动端方案初始化适龄提示单选项，默认选中「18+」；用户仍可手动切换其他选项
适龄提示切换关闭、8+、12+、16+、18+ 均可选择；适龄按钮展示时机、详情链接、按钮百分比等字段保持展示
时长限制字段「未成年及游客时长限制」整行隐藏，不参与页面展示；其余协议、注销和按钮位置配置不受影响
保存方案保存当前表单数据及适龄提示选中值；仅保存用户当前编辑的方案，不修改其他方案
取消编辑放弃本次修改并返回列表，不写入当前方案草稿
字段说明明细
字段类型 / 默认值说明
适龄提示单选 / 新建默认 18+可选关闭、8+、12+、16+、18+；历史方案按原值回显
未成年及游客时长限制隐藏本版本不在编辑页展示该字段，历史数据不做迁移或清理
验收标准验收
  • 新建移动端 SDK 方案进入编辑页后，适龄提示默认选中「18+」。
  • 打开任一历史移动端方案时，适龄提示保持该方案原有值，不被重置为「18+」。
  • 适龄提示详情链接输入框正常显示，适龄按钮展示时机不异常换行。
  • 「未成年及游客时长限制」字段不可见，其他未成年人合规字段正常显示。
  • 保存、取消、返回列表、查看方案及非移动端编辑流程保持原有行为。
