## 📱 移动设备预览

### 使用浏览器开发者工具
1. **打开开发者工具**：`F12` 或 `右键 > 检查`
2. **切换设备模式**：`Ctrl+Shift+M` (Windows/Linux) 或 `Cmd+Shift+M` (Mac)
3. **选择iPhone设备**：
   - iPhone SE (375x667)
   - iPhone 6/7/8 (375x667)
   - iPhone 12/13 (390x844)

### Chrome DevTools详细步骤
```
1. F12 打开DevTools
2. 点击左上角 📱 设备切换按钮
3. 在顶部下拉菜单选择设备型号
4. 自动应用对应分辨率和用户代理
```

## 🐛 故障排除

### 页面无法加载
✓ 确保已启动HTTP服务器
✓ 检查localhost:8080地址是否正确

### 样式未应用
✓ 刷新浏览器（Ctrl+Shift+Delete清除缓存）
✓ 检查css/style.css文件是否存在

### 脚本错误
✓ 打开开发者工具Console标签查看错误
✓ 确保js/app.js和data/mockData.js都已加载
