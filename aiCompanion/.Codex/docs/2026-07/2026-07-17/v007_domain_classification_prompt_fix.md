## 变更概述

- 修复已绑定游戏/版本场景下，部分隐式游戏问题被误判为泛问题，导致回复没有沿用版本背景 prompt 的问题。

## 本次修改

- 在 `server/src/services/chatService.js` 中补强游戏域判定：
  - 新增对“这款游戏 / 这个版本 / 回坑 / 新手入门 / 优先养什么 / 开局 / 发育 / 资源”等隐式游戏语义的识别。
  - 新增非游戏语境排除，避免把世界杯、天气、品牌等问题误归到游戏域。
- 在 `server/test/chatService.test.js` 中新增回归测试：
  - `我最近回坑这款游戏，现在版本最值得做的事情是什么？`
  - `这款游戏新手入门怎么玩`
  - `这个版本该优先养什么`
  - 保留 `世界杯季军赛什么时候`、`特斯拉是什么品牌` 为非游戏域。

## 验证

- `node server/test/chatService.test.js` 通过。
- 重启本地后端后，`/api/public/chat` 对“我最近回坑这款游戏，现在版本最值得做的事情是什么？”不再反问用户是哪款游戏，已按绑定版本语境作答。
