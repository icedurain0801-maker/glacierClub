# 对话质量评分模块变更记录

日期：2026-07-17

## 本次交付

为机器人管理后台新增“对话质量评分”能力，支持按每一轮机器人回复进行自动评分、后台筛选查看、单轮重算、人工复核。

## 后端变更

1. 新增质量评分表 `chat_message_scores`
   - 记录轮次关联信息：版本、会话、用户消息、机器人消息
   - 记录维度分：准确性、相关性、完整性、安全性、语气
   - 记录总分、等级、风险等级、风险标签、摘要、优缺点
   - 记录人工复核状态、人工分、复核说明、复核人、复核时间

2. 新增评分服务 `server/src/services/qualityScoring.js`
   - 机器人回复落库后异步入队评分
   - 优先尝试模型评分
   - 模型不可用时自动回退到启发式评分，保证后台可用
   - 支持按消息 ID 手动重算
   - 支持人工复核结果写回

3. 新增评分接口 `server/src/routes/quality.js`
   - `GET /api/quality`
   - `GET /api/quality/message/:messageId`
   - `POST /api/quality/message/:messageId/rescore`
   - `POST /api/quality/:scoreId/review`

4. 接入聊天主流程 `server/src/services/chatService.js`
   - 保存机器人消息后自动触发评分队列
   - 评分失败不阻塞正常回包

## 前端变更

1. 后台导航新增“对话质量评分”菜单
2. 新增评分页面 `web/js/pages/quality.js`
   - 汇总卡片
   - 筛选栏
   - 评分列表
   - 轮次详情面板
   - 单轮重算
   - 人工复核
3. 补充页面样式 `web/css/style.css`

## 验证结果

1. 已执行数据库迁移，`008_quality_scores.sql` 成功落库
2. 已验证后台接口可访问
3. 已验证单轮重算成功
4. 已验证人工复核保存成功
5. 已验证新产生的机器人回复会自动写入评分记录，并异步完成评分

## 说明

当前环境未配置评分模型相关密钥，自动评分走了启发式回退逻辑。这不影响后台功能闭环，但评分质量会低于模型评分。
