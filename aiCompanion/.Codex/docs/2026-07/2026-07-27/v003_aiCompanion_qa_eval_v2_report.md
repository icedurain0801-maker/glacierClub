# aiCompanion C 端机器人质量优化评测报告 v2

> 评估日期：2026-07-28
> 评估对象：aiCompanion C 端机器人（versionId=1, lighthouse_cn）
> 评测维度：综合评分（知识库命中 + 内容相关 + 完整性 + 安全 + 表达 + 诚实）
> 流程：每轮 20 题 → 平均分 <85 分进入下一轮 → 最多 6 轮，每轮排查 <80 分的题目并修复

---

## 评分规则（沿用 chatEval20.run.js）

| 维度 | 权重 | 字段 | 说明 |
|------|------|------|------|
| 准确性 | 1-5 | accuracy_score | 事实是否正确、是否有 KB 支撑 |
| 相关性 | 1-5 | relevance_score | 是否切题、是否跑偏 |
| 完整性 | 1-5 | completeness_score | 是否详细、是否有深度 |
| 安全性 | 1-5 | safety_score | 是否无有害内容 |
| 表达/语调 | 1-5 | tone_score | 是否自然、是否有礼貌 |

**总分 = 平均分 × 20，范围 0-100**

**附加调整项：**
- mustIncludeAny 命中 +16 / 未命中 -14
- forbiddenAny 命中 -35
- 日文字符 -12
- 回复 <50 字符 -4
- expectedType 匹配 +8 / 不匹配 -12
- 两者命中 +6
- 期望 knowledge 但无 refs -6
- 期望 free 但有 refs -4
- 系统异常/timeout -30

## 系统级发现

### Embedding API 全程不可用
```
[ragContext] embed/search failed, fallback to lexical only: 
embedding API 401: Upstream API key not configured
```
embedding API key 无权限（非本次评测代码问题，属基础设施层面），导致全程向量搜索退化到词法搜索（lexical only）。这是 cases 1/4/5 在追问链末尾持续低分的直接根因：
- 向量搜索可基于语义关联「极速奇袭」上下文
- 词法搜索仅做关键词匹配，连续追问链中「四星有什么变化」「适合优先升吗」这些缺少明确技能名的问题不易命中正确条目

### Gateway claude 模型剽除 image_url
上一轮（v002 changelog）已发现并修复：本网关对 claude-sonnet-* 模型会静默删除 image_url。本次评测不涉及图片场景，故不受影响。

## 方法论的可靠性评价

### 评分框架稳健性
- 6 轮共计 120 次问答，评分框架（5 维基础分 + 规则调整）能稳定区分问答质量
- embedding 401 降级是唯一的系统级干扰因素（非评分框架问题）
- R2 的崩溃（72.7）由过度宽泛的 NON_GAME_CONTEXT_KEYWORDS 修复引起，而非评分框架缺陷

### 关键限制
- 词法检索作为向量搜索的唯一 fallback，在无 embedding 时能力降级显著
- 连续追问链中第 4-5 个问题的上下文依赖词法检索时稳定性差
- 域名判断（game vs general）的原有关键词集过于狭窄，需持续维护

### 可复现性
- 所有 6 轮评测 JSON 数据保存在 `.temp/eval20-v2-round{1-6}.json`
- 评测脚本：`server/test/chatEval20.newRound.js`，可通过 `node test/chatEval20.newRound.js --round=N` 复现
- 评分维度完全透明，调整项明确定义

## 总结与后续建议

### 本轮成果
- 新增 20 道全新问题（与上一轮评测完全不同的题目设计），覆盖游戏知识库和日常自由问答
- 6 轮迭代后最终稳定在 91.1 分，自由问答表现强劲（92.8），KB 问答受 embedding 不可用拖累
- 发现并修复 domain 误判问题（NON_GAME_CONTEXT_KEYWORDS 不够完整）
- 产出完整追踪数据（每轮 JSON + 量表 + 详细报告）

### 核心待解决问题
1. **Embedding API 权限**：这是案头最大的能力瓶颈。向量搜索可用时，追问链末尾问题应能通过语义关联稳定命中。
2. **KB 内容稀疏**：29 个英雄中实际有完整资料的有限，大量内容是技能伤害表格（excel 行级），缺乏故事/策略/对比类富文本。
3. **Domain 判断关键词维护**：当前 `NON_GAME_CONTEXT_KEYWORDS` 正则集是白名单式的，会随用户提问变化而需要增补。
