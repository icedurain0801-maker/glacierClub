# v004 Changelog

## 变更概述

修复 C 端聊天中“有什么攻略推荐”这类泛问被错误挂载知识库配图和参考条目的问题。

## 变更内容

- 在 RAG 参考过滤中增加泛攻略问法识别：当用户没有提供具体游戏、角色、关卡等对象时，不返回随机高分参考资料。
- 在聊天回复保存前增加追问型回答判断：当机器人实际是在追问“哪款游戏 / 游戏名 / 卡在哪”等关键信息时，清空本轮 refs，避免前端展示不相关图片和参考编号。
- 补充单元测试覆盖泛攻略问法和追问回复的 refs 抑制逻辑。
