# v005 Changelog

## 变更概述

修复 C 端机器人在用户切换到赛事/时间类新话题时，错误沿用上一轮英雄上下文并返回英雄卡片的问题。

## 变更内容

- 收紧英雄卡片触发条件：寒暄、世界杯/比赛/决赛/赛程/比分、时间询问、天气、新闻、价格、搜索等新话题不再触发英雄卡片回复。
- 保留明确英雄短名的卡片触发能力，例如用户直接发送“薇珀”仍可命中英雄档案。
- 补充单元测试覆盖“世界杯决赛什么时候”不应触发英雄卡片的场景。
